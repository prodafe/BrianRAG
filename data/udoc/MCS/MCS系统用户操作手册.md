## 一、概述
### 1. 系统概述
随着光伏行业机器人的发展，对于物料调配和设备联机业务的需求越来越复杂，逐渐发展出一套系统来分离机器人调度和物料调度设备联机，降低系统复杂度，分而治之，从而诞生了MCS。MCS主要包含合理分派任务，掌握物料的流向，产线划分，产能平衡控制等功能。

## 二、操作步骤
### 1. 系统登录
#### 1.1 系统登录
1. 在网址输入框输入已部署好的系统前端的网址（端口：8100）如：淮安捷泰：http://172.25.90.247:8100/login ![系统登录页面](./004_系统登录页面.png)
2. 输入用户名和密码进入系统后，选择`企业应用 -- MCS`进入调度页面![系统登录页面2](./005_系统登录页面2.png)
#### 1.2 用户管理

##### 1.2.1 添加新用户（管理员权限的账户可进入)

1. 进入用户管理页面，选择用户管理
2. 点击“+”添加新用户
3. 填写用户信息
4. 保存后，输入的手机号这一栏将作为登录用的用户名，密码默认为 123456（登录后可修改密码 ）![用户管理页面](./006_用户管理页面.png)
5. 添加完用户后点击“赋权”给用户分配权限![用户赋权](./007_用户赋权.png)



##### 1.2.2 修改密码

1. 用户登录后，点击右上角的头像
2. 修改密码![修改密码](./008_修改密码.png)



### 2. 基础配置

   | 描述     | 一般为机台号+上下料，主要用于定线页面的显示                  |                                                              |
   | 模板类型 | 下拉列表选择，对应机台类型                                   | 自动化：自动化机台<br />暂存: 缓存站 <br />QC: 未知 (暂未定义) |

| DockType                  | 设备轨道类型                                                 | 单轨single<br />双轨Double                                   |

| FromMachines              | 设备可以上哪些设备下的料（值为设备组里的）可以设置多个设备(以英文逗号分隔) |                                                              |

| GetTrack                  | 进料轨道                                                     | Track1：机器人的左上一轨道进料动作（面对机器人）<br /> Track2：机器人的右上一轨道进料动作（面对机器人） <br />Track3：机器人的左下一轨道进料动作（面对机器人）<br /> Track4：机器人的右下一轨道进料动作（面对机器人） <br />Track1&Track2：机器人的第二层轨道进料动作（面对机器人） <br />Track3&Track4：机器人的第一层轨道进料动作（面对机器人） |
| IsSplitMerge              | 是否允许拆分上下料动作                                       |                                                              |

| IsDryProcess              | 是否干式设备(干式设备可限制出料，湿式不可，必须直接出料)     | True（干区） <br />False（湿区）                             |
| MutexCount                | 互斥任务触发值，当上下料轨道上的花篮数大于该值时优先产生下料任务，小于该值时优先产生上料任务 |                                                              |
| MutexMachine              | 互斥机台（一般是上下料距离过近的机台设置）                   |                                                              |

| PsgMachineOrder           | 可送Psg设备顺序（暂时无此需求）                              |                                                              |

| PutTrack                  | 出料轨道                                                     | Track1：机器人的左上一轨道出料动作（面对机器人） <br />Track2：机器人的右上一轨道出料动作（面对机器人） <br />Track3：机器人的左下一轨道出料动作（面对机器人） <br />Track4：机器人的右下一轨道出料动作（面对机器人） <br />Track1&Track2：机器人的第二层轨道出料动作（面对机器人） <br />Track3&Track4：机器人的第一层轨道出料动作（面对机器人） |
| SecondLayer               | 机器人第二层轨道动作（没有轨道动作就不用设置，若设置错了可以改成OFF） | GET（进料） <br />PUT（出料）                                |
| ToBuffers                 | 该设备下料可以送往哪些暂存站（值为设备组里的）可以设置多个暂存站（以英文逗号分隔） |                                                              |
| ToMachines                | 该设备下料可以送往哪些设备（值为设备组里的）可以设置多个设备（以英文逗号分隔） | TrackType1：左上一轨道花篮类型（面对机器人） <br />TrackType2：右上一轨道花篮类型（面对机器人）<br />TrackType3：左下一轨道花篮类型（面对机器人）<br />TrackType4：右下一轨道花篮类型（面对机器人）（没有轨道动作不用设置，若设置错了可以选OFF）Empty：空花篮，Full：满花篮 |
| AcceptTimely              | 分配及时时间(单位:秒)，用以判断该设备任务接收是否及时。任务创建时间与接收时间间隔，若小于此时间，则为及时。最终在“及时率”报表展现。 |                                                              |
| ConfirmTimely             | 移动及时时间(单位:秒)，用以判断该设备任务接收是否及时。接收时间与机器人到位时间间隔，若小于此时间，则为及时。最终在“及时率”报表展现。 |                                                              |

##### 2.2.3 机台互斥功能的配置

此功能主要用于一些特殊机台，由于上下料对接口离得过近，需要添加互斥功能，使得上下料的任务不会在同一时间生成导致机器人运行不顺畅。

互斥功能的配置在设备配置项为 `基础配置-设备配置` 中 ![互斥配置](./019_互斥配置.png)

**互斥配置属性参数说明**

| 属性                     | 说明                                                         | 可选值 |
| ------------------------ | ------------------------------------------------------------ | ------ |
| MutexCount（互斥生效值） | 当MutexCount设置在上料对接口时，上下料轨道花篮数之和小于等于互斥值时，只生成上料任务；当MutexCount设置在下料对接口时，上下料轨道花篮数之和大于等于互斥值时，只生成下料任务； |        |
| MutexMachine（互斥机台） | 与当前机台对接口互斥的另一个对接口的设备ID，两边都要设置互斥（注：互斥仅用于同一机台的上下料对接口  如：正膜1上料 和 正膜1下料） |        |

**设备组属性说明**

| 属性       | 说明                                                         | 可选值 |
| ---------- | ------------------------------------------------------------ | ------ |
| 设备组名称 | 组名（自定义）定线后自动生成                                 |        |
| 设备组成员 | 组成员（多选，列表为已加的所有设备）                         |        |

| minValue   | 目前无实际意义（缓存站分组中，机器人携带该组设备中料的车数【按照轨道计算需要机器人数 X2】实际数量小于该值时，将产生从暂存中取料的任务） |        |
| 描述       | 自定义描述                                                   |        |

注：暂存需要每一台每一层都做一个分组作为基础（最大值和最小值起作用），当该暂存的指定层存放的物料空闲在制2大于maxvalue（最大值）时，会往该暂存的指定层送物料；若空闲在制2小于minvalue（最小值）时，将会从该暂存指定层接出物料。  2为【按照轨道计算需要机器人数 X2】
暂存配置里最大值和最小值生效优先级大于设备组配置

### 3. 设备任务

#### 3.1 实时任务

正在进行的任务，MCS根据采集到的机台信息判断满足条件则生成任务

- 搜索：一般可以搜索机台查找任务，或者搜索机器人号
- 取消任务： 找到想要取消的任务对应的取消键，点击取消按钮后可点击刷新按钮，查看任务是否已取消成功。（不能直接取消，先在mcs里取消，再去rms里取消对应任务）如果是双口暂存则不能取消任务，必须等任务做完。
- 任务状态 ：
  - SendSuccess ：成功发送任务到rms
  - Cancel：任务取消
  -  Fail：任务失败
  - MESProcessed：MCS系统发出任务，但未发送到RMS系统，无法正常叫车
  - WaitingCancel：等待被取消
  - Confirmed：机器人已到达机台，并且二次确认
  - Accepted：已被rms接收

![实时任务](./027_实时任务.png)

#### 3.2 添加任务

2. 保存后，刷新页面看是否发送成功，查看任务状态是否为 SendSuccess 如果是就发送成功

### 4. 设备定线

#### 4.1 当前定线

在当前定线中我们可以查看到当前已定的线别只能查看，不能添加、删除和修改，（分配权限时可以允许用户使用该功能）

#### 4.2 预定线

机器人只能运输到定线中指定的机台，不能运输到其他定线或者未定线中的机台。因工艺需要，定线可使机器人运输到指定线别机台，以达到不混料的目的

在预定线中，会有每个工艺段的一列，在这一列的最下方有该工艺段所有自动化机台。选择需要定线的线别，双击需要定线的自动化机台即可加入该线别，并依次点击暂存、 使用，即完成定线。  (注：任何线别的自动化，做出任何动作后，都需要暂存使用后才可生效)

同一时间内，预定线页面只允许一位用户进入查看和修改

![预定线](./031_预定线.png)

##### 4.2.1 定线操作步骤

1. 点击“新增”
2. 输入名称（保存后不能修改）
3. 保存
4. 选择该定线
5. 双击选择机台，移动到定线
6. 点击“暂存”保存修改，上方会显示暂存成功
7. 点击“使用”，启用定线上方会显示使用成功

![新增定线1](./032_新增定线1.png) ![新增定线2](./033_新增定线2.png)

**定线状态说明**

- 暂存：保存修改，但是不会生效
- 使用：使用当前定线，修改的内容会启用
- 恢复：当前定线恢复到修改之前的状态（暂存后也能恢复，使用定线后恢复不了）
- 禁用：禁止使用当前定线
- 取消：撤回当前的修改（暂存后不能取消）
- 删除线：删除当前定线（启用状态下不可直接删除，需先禁用再删除）

#### 7.2 配置OPC

1. 点击“+”新增 ![配置OPC步骤1](.\051_配置OPC步骤1.png)
2. 找到OPC地址及点位标签，首先在IP配置表中找到对应的机台，确认机台IP，一般同一机台只有一个IP（SE设备上下料分别使用不同的IP，碱抛、RCA中转和下料分别使用不同IP），然后OPC为 opc.tcp://localhost:4840 ，localhost用IP地址代替如图 前硼扩上下料的OPC地址都为opc.tcp://172.25.80.25:4840 ![IP配置表](.\055_IP配置表.png)
3. 打开 Softing OPC UA Client 在 `Project -- add Session `双击创建，然后在右侧`Endpoint Url `这栏输入OPC地址 ：opc.tcp://172.25.80.25:4840 ，最后点击下方`Validate Connection `查看是否连接成功，若是成功点击 OK 进入![配置OPC步骤2](.\052_配置OPC步骤2.png)
4. 在 Configuration下找到对应的文件位置 此处 `vs_LoadCasNum` 为上料花篮点位数量右侧 `Properties`下 `Node Id -- Value` ， `Value`值为标签，复制粘贴到标签名称中（如果找不到窗口，在View下查看视图是否打开）![配置OPC步骤3](.\053_配置OPC步骤3.png)
5. 配置完成后点击保存，刷新一下点位状态，查看是否为true，如果为true则能读取到点位信息，如果为false则表示无法读取，需要查看配置以及网络是否出错。若确认配置无误可以联系自动化机台的厂商协助解决![配置OPC步骤4](.\054_配置OPC步骤4.png)

**OPC配置字段说明**

| 字段     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 设备id   | 基础配置--设备配置--设备id                                   |
| 标签名称 | 在OPC UA Client里查找对应的文件位置， 复制Node Id 的 Value值， (一般自动化厂商会提供对应的文件位置) |
| 项目操作 | 进料轨道的花篮数 选 Load<br/>出料轨道的花篮数 选 Unload<br/>轨道的屏蔽点位   选 DisableAGV |
| 网址     | opc地址，一般为opc.tcp://localhost:4840，localhost用机台分配的ip替代，端口号默认4840（例外，SE2机台的端口号为9347，opc.tcp://172.25.73.2:9347） |
| 标志     | 对应的层数 ，1代表第一层，2代表第二层                        |
| 模板类型 | 默认选 TextureOn                                             |
| 描述     | 默认选 Robot（自动化）如果为告警信息，如暂存告警，则选 Alarm |
| 需要订阅 | 默认 Y （大写，代表启用）                                    |
| 采样间隔 | 读取点位信息的时间间隔，单位ms，默认 1000 （1000ms）         |

注：以上填空不允许有空格，有空格必定导致读取不了点位
