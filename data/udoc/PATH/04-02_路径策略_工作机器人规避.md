## 一、概述

本文件介绍了“避开正在工作的机器人”功能的配置与应用场景。该功能适用于当某机器人（如 A）在主通道执行任务、造成后续机器人排队拥堵的情况。通过配置规避机制，系统可引导后续机器人选择其他路径，绕开指定工作点位，从而缓解通行压力。文档支持按机器人名称、类型进行灵活配置，并可设定具体的工作点位作为规避依据。

## 二、配置需要规避的机器人

1.  如果想指定单独的机器人：

| 参数名称                | 参数值                |
| ------------------- | ------------------ |
| avoid_working_robot | ubot-001, ubot-002 |

2.  如果想指定一个类型的机器人：
>格式：type:<车的类型1>,<车的类型2>


| 参数名称                | 参数值                 |
| ------------------- | ------------------- |
| avoid_working_robot | type:Bot600,Flex500 |

屏蔽类型为 Bot600 和 Flex500 的机器人

## 三、屏蔽工作的路径点


| 参数名称                 | 参数值       |
| -------------------- | --------- |
| avoid_working_points | p101,p102 |

**实现效果为，在 avoid_working_robot 列表内的机器人，占据 avoid_working_points 的点位时，其他机器人需要避开这些点位进行绕路。**
