## 一、概述

本文件介绍了机器人分配路径优先级的配置方法。通过该机制，可根据机器人名称或类型设定其路径分配的优先级，以实现更精细的调度控制。系统在分配路径时将优先考虑优先级高的机器人；当多个机器人处于同一级别时，将采用随机方式决定顺序。默认优先级为 0，数值越大表示优先级越高。

## 二、配置方法

系统内的机器人默认优先级为0，优先级数值越大表示优先分配机器人的路径。

- 其中优先分配的路径节点是已经释放的路径节点，已经分配的路径不会受此优先级影响。

- 同一优先级的机器人之间分配顺序随机

从下表中可以查看机器人对应的类型 type
![](img/robotType%202.png)

设定 path 参数名称 robot_type_priority

1.  根据机器人类型的优先级设定
>值：type:<机器人类型>:<优先级>

| 参数名称                | 参数值            |
| ------------------- | -------------- |
| robot_type_priority | type:Flex500:1 |

2.  为某一辆机器人设置优先级
>值：<机器人名>:<优先级>

| 参数名称                | 参数值        |
| ------------------- | ---------- |
| robot_type_priority | ubot-001:1 |
