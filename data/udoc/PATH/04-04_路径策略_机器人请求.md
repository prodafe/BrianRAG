## 一、概述

本文件介绍了新建机器人请求相关的功能与配置，主要包括“请求锁点”和“请求旋转”两类操作。文档详细说明了各类请求的触发逻辑与应用场景，并列出了相关的配置参数，支持用户根据需求灵活调整机器人在路径规划与动作执行过程中的控制策略。

## 二、请求类型

- 当前新建的 request 类型分为【锁点】和【旋转】，具体的申请名称可区分为：

	- 请求锁点
		- point：提供具体点位，其他机器人不得分配该点位
		- turn_point：提供旋转坐标和半径，path 进行该范围内的锁点，其他机器人不得分配该点位
	- 请求旋转
		- turn：提供坐标和半径，附近点位（一个阈值的距离内）不批准其他机器人的 turn 请求

- 在发送 request 的阶段

	- 若收到服务器的回复，无论结果是true成功还是false失败，下一次发送新的请求要创建新的 id，避免出现在同一个id上，返回了false，后续又返回true

	- 若没有收到服务器的回复，可用同样的 id 进行重发

	- 对已经成功的 request id 进行记录（视为活跃请求），若服务器收到的请求 id 已经记录 true，不进行计算，直接返回 true

	- 一台机器人同一时间只能有一个活跃请求（区分锁点/旋转申请），在释放 release 当前活跃请求之前，对于新的 request id，一律返回 false

- 在发送 release 的阶段

	- 注意发送 release 的时间节点，是机器人完成了相关的操作，确认可释放相关请求

	- 若没有收到服务器的回复，则用同样的 id 进行重发，确保收到服务器的回复

	- 收到 release 请求的服务器，会把当前活跃的 request 释放

	- release 始终会收到 true

- point/turn_point 和 turn 分别设有 timeout，过了 timeout 之后自动释放请求

- 若机器人处在 disable 或者 lost 的状态，释放活跃请求

## 三、锁点请求

- 当机器人在运行过程中，要主动申请占用点位时，通过 use_point_request_s 启用此功能

- 开启端口接收机器人发出的锁点请求（包括 request_point, request_turn_point），并对机器人的锁点回复审批。

- request_point: 请求中直接说明要申请的路径点位，例如用于机器人后退重新对接

- request_turn_point: 请求中说明坐标及半径，由 RmsPath 来计算所需要申请的路径点位，例如用于舟车的拐弯

- 针对 request_turn_point

	- turn_map_split 参数：将地图上的路径点划分为多个区域，加速审批效率

	- max_turn_radius_mm：区域边界的拓展，可设定一个较大的值，如机器人直径的2倍

	- turn_map_bleed_mm：地图边界的拓展，避免机器人发送的坐标位于路径点集合的范围之外

- 注意：

	- 批准的机器人锁点请求，会在 use_point_request_s 秒后超时并自动释放

	- 若机器人进入 lost 或者 disable 状态，批准的锁点请求会被自动释放

- 相关参数列表：

| 参数名称                      | 单位  | 参数说明                                                                             |
| ------------------------- | --- | -------------------------------------------------------------------------------- |
| ***use_point_request_s*** | 秒   | 值为 0 时关闭，值大于 0 时表示开启锁点请求功能，且值表示成功请求过期的秒数，**请求成功后 use_point_request_s 秒会自动超时释放。** |
| max_turn_radius_mm        | 毫米  | 表示现场所有机器人的最大旋转半径，用于查询相邻机器人或路径点的范围参考，值为 0 或者空的时候，默认值为机器人直径的2倍。【注意填写内容】            |
| turn_map_split_x          | 整数  | （未上线）默认值为 1，表示沿地图 x 轴的切分数量，将地图划分为 turn_map_split_(x * y) 个区域                     |
| turn_map_split_y          | 整数  | （未上线）默认值为 1，表示沿地图 y 轴的切分数量，将地图划分为 turn_map_split_(x * y) 个区域                     |
| turn_map_bleed_mm         | 毫米  | （未上线）默认值为 1000，表示地图边界的出血量，避免请求旋转的坐标不在地图范围内时导致的报错                                 |

### 3.1 自动旋转锁点配置（未上线）

- 描述：

	- 将机器人向 path 服务请求锁点的功能自动化

	- 机器人行进路线中，逢节点转角超出一定的阈值，就自动进行申请。

	- 机器人行驶至拐点的下一个路径点之后，会释放之前申请的旋转锁点（超时释放会覆盖此设定，避免设置太小的超时时间）

- 需要配置上文 **use_point_request_s** 开启锁点服务

- 相关参数列表：

| 参数名称                     | 参数值                                     | 参数说明                     |
| ------------------------ | --------------------------------------- | ------------------------ |
| auto_turn_request_robot  | 指定具体机器人例子：<br><br>ubot-001,ubot-002     | 自动旋转锁点的机器人               |
| auto_turn_request_robot  | 指定某类型机器人例子：<br><br>type:Flex500,uBot300 | 自动旋转锁点的机器人               |
| auto_turn_request_robot  | 指定某区域机器人例子：<br><br>zone:JW              | 自动旋转锁点的机器人               |
| auto_turn_request_degree | 默认值：30                                  | 角度阈值，大于此角度的节点转角将自动申请旋转锁点 |

### 3.2 机器人和料箱的模型配置

- 在表 robot_model 中填写各个机器人和料箱类型的尺寸

| 参数名称                | 参数值                       | 参数说明       |
| ------------------- | ------------------------- | ---------- |
| category            | string，如：robot 或者 shelve  | 分类机器人或料箱   |
| name                | string，如：default, Flex500 | 机器人或料箱类型名称 |
| length_front_mm     | float                     | 体积前长       |
| length_rear_mm      | float                     | 体积后长       |
| width_mm            | float                     | 体积全宽       |
| safety_threshold_mm | float，默认：50               | 体积的安全参数    |

- 现场根据机器人类型、货架类型填写模型参数

- 料架模型

	- 若机器人状态包 lift_state = 1，获取料架类型 shelveType，并查询对应的模型。

	- 如果查不到对应的料架模型，则用默认料架模型 shelve - default

- 机器人模型

	- 根据机器人在 robot 表里的类型，查询对应的机器人模型。

	- 机器人的默认模型，采用 path_params 表里的机器人模型

## 四、旋转请求

- 应用场景：当相邻节点的机器人，同时旋转会导致碰撞时，机器人在旋转前可向 path 进行申请，避免旋转半径内的机器人同时旋转

- 旋转请求在进行碰撞检测的时候，只会考虑其他机器人当前活跃的旋转请求，不考虑其他机器人通过状态包上传的位置和姿态

- 收发信息内容可参考[【机器人通讯协议】](https://gitee.com/juniontech/rms-path/wikis/%E9%80%9A%E8%AE%AF%E5%8D%8F%E8%AE%AE/AGV%E9%80%9A%E8%AE%AF%E5%8D%8F%E8%AE%AE#send-path-%E5%8D%8F%E8%AE%AE)
