## 一、概述

本文件介绍了穿库位功能的配置方法与应用规则。内容包括穿库位的适用条件、配置流程，以及机器人在经过穿库位时的避让策略。支持设置“满载避让”与“所有车避让”等控制模式，用于保障穿库位通行的安全性与通畅性，特别适用于库位场景下的路径精细控制。

## 二、配置方法

在 `application.properties` 设置更新Redis数据

```
useRedis = true
updateShelve = true
```

在数据库 `path_params` 中设置


| 参数名称                      | 参数值 | 描述                           |
| ------------------------- | --- | ---------------------------- |
| avoid_shelves             | 1   | 打开穿库位                        |
| avoid_pass_filled_shelves | 0/1 | 0：在机器人处于满载状态时避让<br>1：所有车都是避让 |
