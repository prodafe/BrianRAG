## 一、概述

本文件介绍了获取机器人路径距离的接口使用说明。内容包括接口的基本信息、请求示例、请求参数及返回结果的详细说明，并对各字段含义及接口功能进行了逐一解析。该接口用于计算指定机器人在当前地图环境下，从起点到终点的路径距离，为路径规划与调度策略提供数据支持。

## 二、接口基本信息

| 名称   | 说明               |
| ---- | ---------------- |
| 接口名称 | 获取机器人剩余路径距离      |
| 接口路径 | /api/distances   |
| 请求方法 | GET              |
| 请求参数 | robotNames (可选)  |
| 返回格式 | application/json |
| 认证要求 | 无                |

## 三、请求示例

### 3.1 请求全部机器人距离

```
GET http://localhost:9000/api/distances
```

### 3.2 请求指定机器人距离

```
GET http://localhost:9000/api/distances?robotNames=ubot-001,ubot-999
```

## 四、请求参数说明

| 参数名        | 类型    | 是否必填 | 说明                                                                 |
| ---------- | ----- | ---- | ------------------------------------------------------------------ |
| robotNames | Array | 可选   | 机器人的唯一标识符数组，多个机器人以逗号分隔，例如 ubot-001,ubot-002。若未传入此参数，则返回所有机器人的路径信息。 |

## 五、返回结果说明

### 5.1 返回示例（查询指定机器人）

```json
{
	"robotDistances": {
		"ubot-001": {
			"distance": 5738.474799110973,
			"found": true
		},
		"ubot-999": {
			"distance": null,
			"found": false
		}
	}
}
```

### 5.2 返回示例（未传入robotNames，返回全部机器人信息）

```json
{
	"robotDistances": {
		"ubot-001": {
			"distance": 5738.474799110973,
			"found": true
		},
		"ubot-002": {
			"distance": 10234.567891011121,
			"found": true
		},
		...
	}
}
```

## 六、字段说明


| 字段名            | 类型      | 说明                                          |
| -------------- | ------- | ------------------------------------------- |
| robotDistances | Object  | 包含所有匹配机器人路径信息的对象集合                          |
| {robotName}    | String  | 机器人的唯一标识符，例如 ubot-001                       |
| distance       | Double  | 对应机器人的剩余路径总距离（单位：毫米），如果未找到数据则为 null         |
| found          | Boolean | 指示该机器人是否成功查询到路径数据，true 表示成功，false 表示未找到对应数据 |

## 七、功能说明

- 如果请求中未提供参数 robotNames，则返回系统中所有机器人的剩余路径信息。

- 如果请求中提供了 robotNames，则返回指定机器人的路径信息。如果机器人路径信息未找到，返回 "found": false，并将 distance 设置为 null。
