## 一、概述

本文件介绍了获取机器人剩余路径长度的 API 接口。该接口用于实时查询指定机器人当前任务中**尚未完成的路径长度**，完整和剩余路径点名称，**数据每 2 秒自动更新一次**，便于外部系统获取机器人行进进度、进行调度判断或界面展示。文档包含接口地址、请求参数说明、返回字段定义及调用示例，支持灵活集成与高频访问。

## 二、API 

### 2.1 剩余路径长度

- 接口名称：查询机器人距离信息（支持指定机器人）

  - **请求方式**：GET

  - **接口地址**：`/api/distances`

  - **请求参数**：

    | 参数名       | 类型   | 是否必填 | 描述                                                         |
    | ------------ | ------ | -------- | ------------------------------------------------------------ |
    | `robotNames` | string | 否       | 逗号分隔的机器人名称列表，支持多个，如 `ubot-001,ubot-002`。如果为空，默认查询全部机器人。 |

  - **完整示例**：
     `http://localhost:9000/api/distances?robotNames=robotName1,robotName2`

     `http://localhost:9000/api/distances`

返回示例

- **响应格式**：`application/json`

```json
{
  "robotDistances": {
    "robotName1": {
      "found": true,
      "distance": 7143.577040673661
    },
    "robotName2": {
      "found": false,
      "distance": null
    }
  }
}
```

#### 字段说明：

| 字段名         | 类型         | 描述                                              |
| -------------- | ------------ | ------------------------------------------------- |
| robotDistances | Object       | 包含各个机器人的距离信息                          |
| ubot-001       | Object       | 机器人名称                                        |
| found          | Boolean      | true请求成功，false请求失败（没有任务或者没有车） |
| distance       | Float / null | 如果 found 为 `true`，则为距离数值；否则为 `null` |

### 2.2 路径点

接口名称：查询机器人距离信息（支持指定机器人）
  - **请求方式**：GET
  - **接口地址**：`/api/points`
  - **请求参数**：

| 参数名        | 类型     | 是否必填 | 描述                                                                                                                  |
| ---------- | ------ | ---- | ------------------------------------------------------------------------------------------------------------------- |
| robotNames | string | 否    | 逗号分隔的机器人名称列表，支持多个，如 `ubot-001,ubot-002`。如果为空，默认查询全部机器人。                                                             |
| pathTypes  | string | 否    | 逗号分隔获取路径类型列表，支持多个，当前支持<br>1. "rest"：表示剩余路径点名称<br>2. "whole"：表示完整路径点名称<br>示例：pathTypes=rest,whole<br>如果为空，默认查两种路径点类型 |


  - **完整示例**：
     `http://localhost:9000/api/points?robotNames=ubot-001,ubot-002&pathTypes=whole`
     `http://localhost:9000/api/points`

返回示例

- **响应格式**：`application/json`

```json
{
    "robotPaths": [
        {
	        "name": "ubot-003",
            "rest": ["p13", "p12", "p11", "A"],
            "whole": ["p4", "p3", "p2", "p13", "p12", "p11", "A"]
        },
        {
	        "name": "ubot-002",
	        "rest": ["p8", "p7", "p6", "p5", "p4", "B"],
            "whole": ["p8", "p7", "p6", "p5", "p4", "B"]
        },
        {
	        "name":"ubot-001",
            "rest": [],
            "whole": []
        }
	]
}
```


**注：**
1. 如果指定的机器人路径为空，返回空列表
2. 路径每秒更新一次
