## 一、概述

本文件介绍了机器人控制权转移功能的整体设计与使用方法。内容包括控制权转移的核心功能、适用限制、系统架构实现方式，以及具体的配置方法。该功能支持在多系统或多模块协作场景下，实现对机器人的控制权限动态切换，确保在不同控制方之间安全、平稳地完成接管与释放。

## 二、功能

把整张图分成若干个区域。然不同的`RmsFork`跟`RmsPath`分管不同的区，从而有效利用多核CPU进行并行运算。

## 三、限制

由于死锁检查与预测会在区域边界停止，所以需要人为保证在区域边界的机器人不会与其它机器人形成死锁。

## 四、架构

有一个主控程序(`MainControl`)负责接收会跨区执行任务的机器人的状态然后转发給对应的区域的`RmsFork`或`RmsPath`。发给需要跨区执行任务的机器人的指令也会先发给`MainControl`，由`MainControl`统一转发，这样能避免某个机器人在跨区时同时接到两个服务发的指令。

## 五、配置
### 5.1 地图准备

1. 叉车扫描地图，AGV扫描地图
2. 叉车地图和AGV地图进行对齐，具体参考 [【多地图坐标对齐】](https://doc.weixin.qq.com/doc/w3_AEYAigZHANMJ677JPmOSzWqqaakRC?scode=AJMABQdxAA8Y6TAQiJ) 
3. 在地图上画相应的`MotionManage`区域
在AGV地图上画出AGV跑的区域

### 5.2 MainControl

配置文件路径：`/usr/local/rms/MainControl/config/config.json`
```json
{
  "httpPort": <http端口，主要用于debug>,
  "tcpPort": <tcp端口，用于与RmsFork,RmsPath交互，需要与Path里的配置对应>,
  "plugins": {
    <插件名>: {<插件参数，由具体插件决定>}
  },
  "pathServer": {
    <Path服务名，需要与Path里的配置对应>: {
      "rect": [
      [长方形的4个坐标，minX, minY, maxX, maxY；单位为米]
      ....
      ]
    },
    .....
  }
}
```


例子：
```json
{
  "httpPort": 9183,
  "tcpPort": 10081,
  "plugins": {
    "LegacyAGV": { //用于接收花篮车的状态
      "port": 8401 //udp监听端口，花篮车往这个端口发udp包
    }
  },
  "pathServer": {
    "server1": {
      "rect": [
        [
          -19.376,
          -7.458,
          23.362,
          25.661
        ]
      ]
    },
    "server2": {
      "rect": [
        [
          20.592,
          1.305,
          43.791,
          25.515
        ]
      ]
    }
  }
}
```


#### RmsFork （branch: `maincontrol-plugin`）
再`config.json`里加入
```json
"plugin":{
       "MainControl":{
               "name":<服务名，与MainControl里的PathServer对应>, 
               "region":[<控制区域名,要与对应的Rect>]
       }
	}
```
例子：
```json
  "plugin":{
    "MainControl":{
      "name":"server1",
      "region":[
        "R1"
      ]
    }
  }
```
在`robot.json`里把需要传递控制权的机器人的`NAVType`和`LocatorType`都设成`MainControlJiuWuAGV`。（现在只写了花篮车的控制权传递）

例子：
```json
{
 "ubot-001": {
    "NAVType":"MainControlJiuWuAGV",
    "LocatorType":"MainControlJiuWuAGV"
  }
}
```
如果花篮与叉车混跑，叉车不需要控制权转移。可以`config.json`里设成
```json
"plugin":{
    "MainControl":{"name":"server1","region":["R1"]},
    "JiuWuFork":{"port":9401} //加载玖物叉车插件
}
```
`robot.json`里加
```json
{
 "ubot-001": {
    "NAVType":"MainControlJiuWuAGV",
    "LocatorType":"MainControlJiuWuAGV"
  }
   "P1500": {//叉车
    "NAVType":"JiuWuFork"
    //LocatorType会默认取NAVType的值
  }
}
```

#### RmsPath （branch: `maincontrol-plugin`）
在`application.properties`里加入
```
useMainControl=true
ServerName=<服务名，与MainControl配置对应>
MainControlIP=<MainControl服务的IP，默认127.0.0.1>
MainControlPort=<MainControl服务TCP端口，默认10081>
ControlRegionName=<控制区域的名字，暂时只支持一个区>
```
