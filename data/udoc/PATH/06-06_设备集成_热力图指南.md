## 一、概述

本文件介绍了热力图的配置方法与类型说明。内容包括热力图的用途、支持的热力图类型，以及各类型对应的配置参数与可视化效果设置。通过合理配置，用户可直观了解机器人在场地内的行为分布，辅助优化路径规划与区域管理。

## 二、配置方法

热力图的主要功能是表达机器人在地图上的堵塞情况。相关参数包括：

| 参数名称                  | 单位                                                  | 参数说明                                                 |
| --------------------- | --------------------------------------------------- | ---------------------------------------------------- |
| heatmap_path_type     | restpath, usingpath, location, restpathInTimeWindow | 找路径时根据机器人的 restpath, usingpath 或 location，给每个点加 cost |
| heatmap_weight        | 无                                                   | 增加的 cost = 占用点的机器人的数量 * heatmap_weight               |
| use_heatmap_cost      | 0 或 1                                               | 0 表示热力图仅用于可视化，1 表示热力图用于可视化和路径规划中                     |
| heatmap_time_window_s | 秒                                                   | restpathInTimeWindow 模式的时间窗范围                        |

`/usr/local/rms/RmsPath/config/application.properties` 写入参数

```
heatMap.baseurl=http://127.0.0.1:9044
HeatMapTask=true
```

- heatMap.baseurl: 设定 `<IP>:<端口>`
- HeatMapTask: true 为开启
