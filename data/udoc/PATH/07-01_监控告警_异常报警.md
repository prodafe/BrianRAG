## 一、概述

本文件介绍了 RmsPath 服务的异常警报功能。RmsPath 在运行过程中会持续监测机器人运行状态（堵车、门控异常、路径异常等）。  当检测到异常时，系统通过 **Redis 报警通道** 将报警状态上报给 RMS 服务，实现 500 ms 周期的检测 ，每秒同步的实时监控展示。

## 二、程序配置

1. 功能开关：打开配置文件 `/usr/local/rms/RmsPath/config/application.properties`

```properties
# 开启 redis 服务器功能
useRedis=true

# 配置 redis 服务器名称
redisServerName={serverName}
```


2. RmsPath 参数

| 参数名称                  | 类型     | 默认值         | 描述                   |
| --------------------- | ------ | ----------- | -------------------- |
| redis_alarm_hash      | string | path:alarms | 一般不用调整，修改数据库 hash 名称 |
| alarm_expired_seconds | int    | 600         | 报警的超时清理              |
| alarm_queue_threshold | int    | 5           | 机器人队列长度的报警阈值         |

## 三、报警触发

### 3.1 报警类型

| 3   | Robot stuck     | 机器人避障      |

## 四、数据结构

| 项目           | 示例                          | 说明           |
| ------------ | --------------------------- | ------------ |
| **Redis 类型** | Hash                        | 存放所有机器人的报警状态 |
| **Hash 名称**  | `path:alarms`               | 可根据环境调整      |
| **Key（键）**   | `{robotName}` ，如 `ubot-001` | 机器人唯一标识      |
| **Value（值）** | JSON 字符串                    | 对应该机器人的报警详情  |


## 五、字段定义

| 字段名             | 类型      | 示例                                      | 说明                                                |
| --------------- | ------- | --------------------------------------- | ------------------------------------------------- |
| `life`          | String  | `"ACTIVE"` / `"CLEARED"` / `"INACTIVE"` | 报警当前状态。ACTIVE 表示报警中，CLEARED 表示刚解除，INACTIVE 表示未报警。 |
| `message`       | String  | `"blocked at point P23"`                | 报警描述信息，由 Path 填入，可包含位置、原因等。                       |
| x               | int     | 555464                                  | 机器人 status 坐标 x                                   |
| y               | int     | 28399                                   | 机器人 status 坐标 y                                   |
| `firstRaisedAt` | Instant | 2025-10-28T09:38:11.867Z                | 该报警首次触发的 UTC 时间。                                  |
| `lastRaisedAt`  | Instant | 2025-10-28T09:38:12.873Z                | 最近一次触发或刷新的 UTC 时间。                                |
| `lastClearedAt` | Instant | 2025-10-28T09:38:12.873Z / null         | 该报警解除的 UTC 时间。                                    |
| `revision`      | Long    | 1                                       | 报警版本号，每次 **状态变化（ACTIVE↔CLEARED）** 时自增，用于幂等识别。     |
| `updatedAt`     | Instant | 2025-10-28T09:38:12.873Z                | 最后一次写入 Redis 的 UTC 时间戳。                           |
| `source`        | String  | RmsPath                                 | 报警来源                                              |

示例：

- 警报生成

```json
{
	"life": "ACTIVE", 
	"message": "No path", 
	"x": "555464", 
	"y": "28399", 
	"firstRaisedAt": "2025-10-28T09:38:11.867Z", 
	"lastRaisedAt": "2025-10-28T09:38:12.873Z", 
	"lastClearedAt": "null", 
	"revision": "1", 
	"updatedAt": "2025-10-28T09:38:12.873Z", 
	"source": "RmsPath" 
}
```
