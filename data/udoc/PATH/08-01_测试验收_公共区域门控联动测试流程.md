#### 1. 配置公共区域路径点

- [ ] 配置参数 `common_zone_points`，定义公共调度区节点集合  
- [ ] 验证：我方与对方机器人在区域外不会触发门控开/关门请求  

#### 2. 准备测试环境

- [ ] 将一台我方在线机器人驶入公共区域并停留  

#### 3. 对方尝试进入公共区域

- [ ] 对方机器人通过 HTTP 接口发起锁点申请  
- [ ] 验证返回失败，机器人等待在公共区域外  
- [ ] 验证我方机器人可正常触发门控开/关  

#### 4. 公共区域控制权切换

- [ ] 对方机器人循环发送锁点申请请求  
- [ ] 操作我方机器人驶出公共区域  
- [ ] 验证：对方机器人申请成功并驶入公共区域  
- [ ] 验证：对方机器人可正常触发门控开/关  

#### 5. 验证资源冲突处理

- [ ] 对方机器人仍在公共区域时，向我方机器人发送 `rms-goto` 指令进入公共区域  
- [ ] 验证我方机器人被系统限制进入，调度系统成功避冲突  

#### 6. 对方释放锁点流程

- [ ] 对方机器人驶出公共区域  
- [ ] 验证其发起释放锁点请求，并成功移除锁定记录  

#### 7. 我方自动进入公共区域验证

- [ ] 对方释放锁点前，我方机器人已经设定 `rms-goto` 任务进入公共区域（并被限制在公共区域外）
- [ ] 对方释放锁点，我方机器人自动驶入公共区域  
- [ ] 验证其成功进入，并可正常触发门控操作
