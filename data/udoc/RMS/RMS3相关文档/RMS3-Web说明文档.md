# 搭建配置模块

**搭建配置**模块为RMS基础设施数据的维护模块，在项目实施的前期需要经常使用。包括机器人、资源、库区、地图、系统五个部分的基础设施数据。

## 机器人

### 机器人配置

该页面维护机器人的基础数据，包括机器人名称、IP、所属机器人类型、所属工作区、启用状态及扩展字段。

![image-20260409143029470](img/image-20260409143029470.png)



**筛选区**
筛选条件：机器人名称，机器人IP，工作区。

**列表字段**
机器人名称，类型，型号，IP，扩展字段，工作区，能否启用。

**常用操作**

- 新增：点击“新增”，填写机器人信息后保存。
- 编辑：点击列表中的“编辑”修改机器人信息。
- 删除：点击“删除”移除机器人。
- 启用/禁用：通过列表中的开关单独切换。
- 批量导入：支持上传 `.xls`、`.xlsx`、`.csv` 文件批量导入机器人。
- 下载模板：点击“下载模板”获取导入模板。
- 批量启用：勾选多条机器人记录后点击“快速启用”。
- 批量禁用：勾选多条机器人记录后点击“快速禁用”。
- 批量设置工作区：先勾选机器人，再在右侧选择工作区，点击“设置工作区”。

**使用说明**

- 编辑已有机器人时，机器人名称不可修改。
- 扩展字段可按需新增多组键值，字段类型由“扩展字段”页面预先定义。扩展字段用途在于给不同车增加特殊逻辑。
- 批量设置工作区、批量启用、批量禁用前，需先勾选目标机器人。

### 机器人类型配置

用于维护机器人类型档案，为机器人配置页面提供类型下拉数据。各类型用于调度判断和车的对接方式，常用的机器人大类有:
NORMAL: 调度直接发送routes name方式发送任务到小车；
JUNION_FORK: 玖物叉车，任务发送方式为经由RmsFork转发；
SEER_FORK: 仙工叉车，任务发送方式为经由RmsFork转发。
机器人小类用于细分区别标注，暂无特殊逻辑。
![image-20260407135143](img/image-20260407135143.png)

**筛选区**
筛选条件：机器人类型名称，类别。

**列表字段**
机器人类型名称，子类型，类别，长度(mm)，宽度(mm)，旋转半径(mm)，更新时间，扩展字段。

**常用操作**

- 新增机器人类型
- 编辑机器人类型
- 删除机器人类型

**使用说明**

- 类别来自系统预配置选项，当前可选择值包括NORMAL/JUNION_FORK/SEER_FORK
- 扩展字段可按需新增多组键值，字段类型由“扩展字段”页面预先定义。扩展字段用途在于给不同车型增加特殊逻辑。注意这里是给一类车增加特殊逻辑，而【机器人配置】中的扩展字段是给具体的车增加特殊逻辑。

### 充电策略配置

该页面维护按时间段生效的充电参数，用于不同时间启用不同的充电参数。
![image-20260407144151](img/image-20260407144151.png)
**列表字段**

- 策略编号
- 工作区
- 充电结束阈值，对应于全局的配置参数：full_plus_battery
- 优先充电阈值，对应于全局的配置参数：full_battery
- 强制充电阈值，对应于全局的配置参数：low_battery_limit
- 取料任务最低电量，对应于全局的配置参数：get_low_battery
- 送料任务最低电量，对应于全局的配置参数：put_low_battery
- 最小充电时长(s)，对应于全局的配置参数：min_dock_time
- 最小充电时长电量阈值，对应于全局的配置参数：min_dock_battery
- 开始时间：该组参数生效的开始时间
- 结束时间：该组参数生效的结束时间
- 使能

**常用操作**
新增、编辑、删除、使能开关

**使用说明**

- 该功能的目的在于按峰谷时间段启用不同的充电规则，例如低电价时可以采用更激进的充电策略。
- 各列表字段对应的参数的使用关系可以查询RMS3的充电策略汇总文档。

### 批量切换地图

用于将指定地图批量下发给一个或多个机器人。
![image-20260408095455](img/image-20260408095455.png)
**筛选区**
上传地图：支持将直接上传的地图传到机器人。
机器人选择：可按类型或者具体名称勾选机器人。

**操作说明**

- 支持直接勾选已有地图下发至机器人。
- 支持直接上传地图下发至机器人。
- 地图列表数据来源于【地图配置】页面。

**工作区配置**
用于维护工作区基础信息，并建立工作区与地图、服务器连接信息的关系。工作区是一组资源根据地理特点抽象分开的一个属性，一般情况下不同工作区的机器人、资源、任务互不干涉。
![image-20260408101304](img/image-20260408101304.png)
**筛选区**
筛选条件：工作区名称

**列表字段**

- 工作区编号
- 工作区名称
- 服务器IP：如果该区域有叉车类机器人，或者交管程序明确使用RmsFork，则需要配置服务器IP为RmsFork程序的IP。
- 服务器端口：如果该区域有叉车类机器人，或者交管程序明确使用RmsFork，则需要配置服务器端口为RmsFork程序接收任务的端口。
- 工作区描述
- 地图
- 扩展字段：来源于系统配置/扩展字段的预定义。
- 更新时间
- 使能

**使用说明**

- 工作区的设计考量一般以地理隔开、互不涉及为前提。
- 叉车类机器人的工作区或者交管程序明确使用RmsFork则必须配置服务器IP和端口。
- 不同工作区的任务在分配调度时为并行执行。


## 资源配置

该模块用于维护资源点位或资源对象信息。资源包括停车点，充电点，机台设备料口。
![image-20260408102855](img/image-20260408102855.png)

**筛选区**
筛选条件：名称，类型，描述，工作区，使能。

**列表字段**

- 名称
- 类型：PARK-停车点；DOCK-充电点；DEVICE-机台设备料口。
- 描述
- x坐标：资源点在地图中的位置坐标。
- y坐标：资源点在地图中的位置坐标。
- theta角度：资源点在地图中的位姿角度。
- 状态：当前资源的占用状态：EMPTY-空置 ASSIGNED-已分配  OCCUPIED-已被占用。
- 工作区
- 前置点：某些特殊车型对接某个机台时需要先驶至前置点再做别的调整动作。
- 扩展字段：扩展特殊逻辑。
- 是否启用

**使用说明**

- 支持单记录新增也支持批量新增，批量新增时需下载模板并填写关键数据再进行上传。
- 使能切换支持批量选择后操作。
- 工作区的设置支持批量选择后操作。

## 库区

### 库区配置

库区是用来对库位进行物料分区的一种手段，一个库区，对应多个库位。目前仅预留拓展。

### 库位配置

用于维护具体库位信息。库位是用来暂存物料的地点。
![image-20260408145556](img/image-20260408145556.png)
**筛选区**
筛选条件：名称，所属库区，优先级，包号，是否使能。

**列表字段**

- 名称
- 类型：用于拓展不同的库位逻辑。
- x坐标
- y坐标
- 容量：库位接纳物料数不会超过容量。
- 库区
- 优先级：同批可用库位优先级高者会先使用。
- 前置点：叉车驶进库位时，需先驶至前置点，从前置点到库位中心这部分可能有特殊动作，故需要给库位配置前置点。
- 扩展字段：预留拓展。
- 包号：当前库位存放的物料的包号信息。同一库位存放的物料包号一样
- 使能

**使用说明**

- “包裹内容”支持通过编辑按钮打开键值对窗口进行维护。
- 扩展字段支持选择预定义字段，并根据字段类型录入数值、布尔值、字符串、列表、JSON、日期等内容。

## 系统配置

### 系统参数

维护调度分配逻辑中的参数，具体参数作用建议在参数描述中明确写出。
![image-20260408161103](img/image-20260408161103.png)

### 数据字典

用于维护系统字典项，供下拉选项或枚举值使用。暂无特殊逻辑。
![image-20260408161315](img/image-20260408161315.png)

### 扩展字段

为适配非标准需求，机器人、区域、资源点可能存在一些特殊逻辑，可以在该页面维护一些配置字段，以用于类似现场复用配置。
![image-20260408161813](img/image-20260408161813.png)
**筛选区**
筛选条件：名称，归属类型

**列表字段**

- 名称
- 归属类型：表示该扩展字段可用于哪些对象，ZONE-工作区，TARGET-资源点，ROBOT-机器人，OTHER-其他对象
- 默认值
- 数据类型
- 权重
- 描述
- 使能

### 报警类型

该页面维护报警类型的定义，包括报警的国际化多语言描述，报警的解决方案等信息。
![image-20260408164359](img/image-20260408164359.png)
**筛选区**
筛选字段：报警码，报警类型，报警等级

**列表字段**

- 报警码
- 报警内容：该字段维护报警的国际化多语言描述
- 报警类型：RobotAlarm-机器人本体告警；TaskAssignAlarm-任务分配告警；TaskDockingAlarm-任务对接告警；SystemErrorAlarm-系统错误告警；TaskCreateAlarm-任务创建告警；DeviceAlarm-设备告警。
- 报警等级：WARNING-警告 < ERROR-错误 < FATAL-致命错误；
- 报警描述
- 解决方案

**使用说明**

- 报警内容支持 JSON 格式编辑，也支持通过键值对编辑窗口维护。
- 报警等级当前前端可选值包括 `ERROR`、`WARNING`、`FATAL`。
- 编辑时报警码不可修改。
- 批量删除前需要先勾选目标记录。

### 授权管理

该页面可以查看调度服务的证书到期时间，当证书到期后，程序会停止调度。该页面可以直接上传证书文件。
![image-20260408170035](img/image-20260408170035.png)
**使用说明**

- 仅支持上传 `.crt` 授权文件。
- 页面一次仅允许选择一个文件，重新选择会覆盖上一个文件。
- 选择文件后，点击“确认上传”完成授权更新。
- 证书生成方法可参考RMS3证书生成工具使用文档。

# 运营管理模块

## 服务运行监控

### 首页

本页面为**服务运行监控（首页）**，用于实时展示CPU、内存、服务器、Java虚拟机及磁盘等核心资源的运行状态，帮助运维人员快速掌握系统健康度与资源消耗情况。

![image-20260420104641170](img/image-20260420104641170.png)

## 任务管理

### 实时任务

**实时任务**页面是用于集中展示系统中所有实时任务的状态与详情，支持多维度查询与任务干预，帮助运维人员实时掌握任务执行进度、处理异常任务，保障业务流程高效运转。

![image-20260420104703984](img/image-20260420104703984.png)

**筛选区**

筛选条件：查询任务编号、目标点、机器人、任务状态、任务类型、工作区

操作按钮：重置（清空条件）、搜索（查询数据）

**优先级修改**

点击数字处，修改任务的优先级级别

![image-20260420104718172](img/image-20260420104718172.png)

**关闭操作**

选择机器人上不保留物料，放料任务将清空物料包号

![image-20260420104730690](img/image-20260420104730690.png)

### 历史任务管理

本页面为**历史任务管理**模块，用于查询、统计和导出机器人历史任务数据，支持多维度筛选与任务量分析，满足运维与业务复盘需求。

![image-20260420104743330](img/image-20260420104743330.png)

1. **筛选区**

   筛选条件：查询时间区间、任务编号、机器人名称、任务类型、工作区

   操作按钮：重置（清空条件）、搜索（查询数据）

2. **数据表格**

   用于展示目标点维度的任务统计数据：

   列表信息：任务编号、目标点、机器人、所属工作区、任务类型、任务来源、创建时间、开始时间、确认时间、结束时间、备注信息

3. **导出功能**

   支持将当前筛选结果导出为文件，用于离线分析或存档

## 机器人管理

### 实时AGV

本页面为**实时 AGV 监控模块**，用于集中展示和管理所有 AGV 设备的运行状态

![image-20260420104759601](img/image-20260420104759601.png)

1. **设备状态可视化**

   **设备基础信息**：展示每台 AGV 的名称、IP 地址、型号、所属工作区等核心信息

   **在线状态**：直观标记设备在线 / 离线状态（如 “uBot-027 离线”）

   **运行状态**：通过标签展示当前状态（如 “空闲”），便于快速识别设备可用性

   **关键业务数据**：实时显示当前任务编号、物料编号、使能状态及电量信息（如电量 100%）

2. **设备控制操作**

   提供**空闲**、**停止**等快捷操作按钮，可直接对 AGV 下发状态控制指令。

   提供**详情**按钮，支持查看单台 AGV 的完整运行数据与历史记录。

   支持**使能开关**，可启用 / 禁用 AGV 设备

   点击详情按钮后，可编辑AGV 身上的物料信息，下拉框选择目前物料表里面存在的物料名称，点击确认,可将包号信息绑定到机器人身上

   ![image-20260420104829761](img/image-20260420104829761.png)

### 电池标定信息

本页面为**电池标定信息管理模块**，用于记录、查询和管理机器人电池电量标定的数据，支持多维度筛选、数据导出与标定解除操作，为电池性能分析与电量校准提供数据支撑。

![image-20260420104843827](img/image-20260420104843827.png)

**筛选区**

1.筛选条件：查询时间区间、机器人名称、状态

2.操作按钮：重置（清空条件）、搜索（查询数据）

**导出功能**

支持将当前筛选结果导出为文件，用于离线分析或存档

**解除标定**

选择指定的机器人，点击解除标定，可以将机器人改为非标定状态

![image-20260420104856585](img/image-20260420104856585.png)

### 交通信息

**交通信息**页面用于展示机器人的交通阻塞与执行任务交通信息，帮助运维人员实时掌握机器人通行状态、阻塞关系与后续任务规划，保障多机器人协同调度的顺畅与高效。

![image-20260420104907809](img/image-20260420104907809.png)

**筛选区**

1.筛选条件：查询AGV编号、目标点、阻挡AGV编号

2.操作按钮：重置（清空条件）、搜索（查询数据）
