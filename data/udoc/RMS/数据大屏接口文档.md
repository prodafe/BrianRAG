# 数据大屏接口文档

## 1. 后端对接

### 1.1. 电池片车状态对接

> rms提供如下接口给webeye调

描述：

|接口参数|参数说明|
|---|---|
| 名称   | 机器人详细信息查询 |
| 方式   | http post |
| 地址   | http://ip 地址:8200/mission/detail |

请求体：

| 参数名     | 类型    | 必填   | 参数说明                      |
| --------- | ------  | ------ | ---------------------------- |
| command   | String  | 是     | 固定“detail”     |
| request   | String  | 否     | 可传空字符串      |
| robot     | String  | 否     | 传空字符串，代表查询所有的机器人 |

响应体：

| 参数名     | 类型   | 参数说明   |
| --------- | ------ | ------ |
| result    | int  | 1-成功,2-失败     |
| message   | String  | 返回信息     |
| robots     | Array  |     |
|   name     | String  | 车名     |
|   ip     | String  | 车ip     |
|   motor     | int  | 是否急停 0代表急停     |
|   mode     | String  | 车mode     |
|   status     | String  | 车状态     |
|   rms     | String  | 车rms状态     |
|   pose     | String  | 车位置     |
|   speed     | String  | 车速度     |
|   battery     | int  | 车电量     |
|   zone     | String  | 车所属区域     |
|   seneor     | Array  | 光电4位数组     |
|   payloads     | Array  | 包号数组     |
|   over_time     | Array  | 包号超时时间（秒）     |
|   receive_time     | Date  | 状态接收时间     |
|   offline_time     | int  | 车离线时间     |
|   error_code     | int  | 车错误码     |
|   job_target_charge     | bool  | 是否充电异常     |
|   battery_ntc     | decimal  | 车电池温度     |

输入示例：

```
{
	"command": "detail",
	"request": "",
	"robot": ""
}
```

输出示例：

```
{
	"result": 1,
    "message": "success",
	"robots": [
		{
			"name": "uBot-001",
			"ip": "172.18.14.7",
			"zone": "34",
			"motor": 1,
			"mode": "offline",
			"status": "runto_offline",
			"rms": "busyinterrupted",
			"pose": "0 0 90.0",
			"speed": "30 0",
			"battery": "80",
			"sensor": [
				0,
				0,
				0,
				0
			],
			"payloads": [
				"",
				"",
				"150210220|2021-11-15 10:52:39",
				"150210220|2021-11-15 10:52:39"
			],
			"ostatus": "error",
			"over_time": [
				-1,
				-1,
				-1,
				-1
			],
			"receive_time": "2021-11-30 09:12:06",
			"offline_time": 2,
			"error_code": ""
        }
	]
}
```

### 1.2.仙工车状态对接

> 调度通过udp推送小车的状态至webeye
  注：c#调度中该报文字段取值直接来自XgRobot.SeerRobot类

描述：

|接口参数|参数说明|
|---|---|
| 名称   | 仙工状态接收 |
| 方式   | udp |
| 地址   | ip:5725 |

响应体：

| 参数名     | 类型   | 参数说明   |
| --------- | ------ | ------ |
| Name     | String  | 车名     |
| X     | decimal  | 坐标x     |
| Y     | decimal  | 坐标y     |
| Angel     | decimal  | 角度     |
| IsStop     | bool  | 车是否停止     |
| Emergency     | bool  | 车是否急停     |
| Charging     | bool  | 车是否正在充电     |
| Blocked     | bool  | 车是否被阻挡     |
| BlockReason     | int  | 车所属区域     |
| BatteryLevel     | decimal  | 阻挡原因   |
| Errors     | Array  | 车报警数据     |
| TaskStatus     | int  | 任务状态     |

输出示例：

```
{
	"Name": "后道_AGV 37",
	"X": -9.9892,
	"Y": 65.16,
	"Angle": -1.572,
	"IsStop": true,
	"Blocked": true,
	"BlockReason": 8,
	"Emergency": false,
	"TaskStatus": 2,
	"Errors": [
		{
			"52200": 1745482789,
			"code": 52200,
			"dateTime": "2025-04-24T16:19:49.074+08:00",
			"desc": "robot is blocked",
			"describe": "robot is blocked",
			"method": "",
			"reason": "",
			"times": 1,
			"timestamp": 1745482789
		}
	],
	"BatteryLevel": 0.72,
	"Charging": false
}
```

## 2. 页面对接

### 2.1. 机器人数据

描述：

|接口参数|参数说明|
|---|---|
| 名称   | 获取工作台的robots |
| 方式   | http get |
| 地址   | http://ip address:port/xxx/robots |

响应体：

| 参数名     | 类型   | 是否必须   | 参数说明   |
| --------- | ------ | ------ | ------ |
| success   | bool  | 是     | 是否成功   |
| code   | int  | 是     | 错误码   |
| message     | String  | 是     | 错误描述   |
| data     | Object  | 是     | 数据区   |
|   num     | int  | 是     | 小车总个数   |
|   stat     | Object  | 是     | 状态统计数据   |
|     estop     | int  | 否     | 急停状态个数   |
|     dock     | int  | 否     | 充电状态个数   |
|     ...     |     |       | 各现场定制状态   |
|   alarmStat     | Object  | 是     | 报警统计数据   |
|     lowBattery     | int  | 否     | 低电量报警   |
|     offLine     | int  | 否     | 离线报警   |
|     ...     |      |       | 各现场定制报警   |
|   list     | Array  | 是     | 车列表   |
|     name     | String  | 是     | 车名   |
|     ip     | String  | 是     | 车ip   |
|     estop     | bool  | 否     | 是否急停   |
|     dock     | bool  | 否     | 车是否在充电   |
|     stop     | bool  | 否     | 车是否停止   |
|     x     | int  | 是     | x坐标，单位mm   |
|     y     | int  | 是     | y坐标，单位mm   |
|     vf     | int  | 是     | 线速度 mm/s   |
|     vr     | int  | 是     | 角速度 度/s   |
|     theta     | decimal  | 是     | 角度   |
|     battery     | int  | 是     | 电量 [1-100]   |
|     content     | String  | 否     | 车包号   |
|     offline     | bool  | 是     | 车是否离线   |
|     alarms     | Array  | 否     | 报警数据   |
|       code     | String  | 否     | 报警码(报警类型唯一标识）   |
|       des     | String  | 否     | 报警描述   |

输出示例：

```
{
	"success": true,
	"code": 0,
	"message": "success",
	"data": {
		"num": 1,
		"stat": {
			"estop": 0,
			"dock": 0
		},
		"alarmStat": {
			"lowBattery": 1,
			"offLine": 0
		},
		"list": [
			{
				"name": "Robot_01",
				"ip": "192.168.1.101",
				"estop": false,
				"dock": true,
				"stop": false,
				"x": 3450,
				"y": 1200,
				"vf": 0,
				"vr": 0,
				"theta": -90,
				"battery": 85,
				"content": "PKG-001",
				"offline": false,
				"alarms": [
					{
						"code": "lowBattery",
						"des": "低电量报警"
					}
				]
```

### 2.2.机台数据

描述：

|接口参数|参数说明|
|---|---|
| 名称   | 获取工作台的机台数据 |
| 方式   | http get |
| 地址   | http://ip address:port/xxx/targets |

响应体：

| 参数名     | 类型   | 必填   | 参数说明   |
| --------- | ------ | ------ | ------   |
| result   | bool  | 是     | 是否成功   |
| code   | int  | 是     | 错误码   |
| message   | String  | 是     | 错误描述   |
| data     | Array  | 是     | 数据区   |
|   id     | int  | 是     | 机台id   |
|   name     | String  | 是     | 机台名称   |
|   x     | int  | 是     | 坐标   |
|   y     | int  | 是     | 坐标   |
|   theta     | decimal  | 是     | 角度   |
|   type     | String  | 否     | 机台类型   |
|   status     | String  | 否     | 机台状态   |
|   robot     | String  | 否     | 当前占用robot   |
|   produceContent     | String  | 否     | 产出包号   |
|   needContent     | String  | 否     | 所需包号   |

输出示例：

```
{
	"success": true,
	"code": 0,
	"message": "success",
	"data": [
		{
			"id": 1,
			"name": "120410811",
			"x": "6784",
			"y": "115513",
			"theta": -90,
			"type": "Device",
			"status": "occpuied"
		}
	]
}
```

### 2.3.库位数据

描述：

|接口参数|参数说明|
|---|---|
| 名称   | 获取工作台的库位数据 |
| 方式   | http get |
| 地址   | http://ip address:port/xxx/storages |

响应体：

| 参数名     | 类型   | 必填   | 参数说明   |
| --------- | ------ | ------ | ------   |
| result   | bool  | 是     | 是否成功   |
| code   | int  | 是     | 错误码   |
| message   | String  | 否     | 错误描述   |
| data     | Array  | 否     | 数据区   |
|   id     | int  | 否     | 库位id   |
|   name     | String  | 否     | 库位名称   |
|   x     | int  | 否     | 坐标   |
|   y     | int  | 否     | 坐标   |
|   theta     | decimal  | 否     | 角度   |
|   robot     | String  | 否     | 当前占用robot   |
|   capacity     | int  | 否     | 叉车库位-容积   |
|   currentNumber     | int  | 否     | 叉车库位-已使用数   |
