# 清洁机器人数据接入文档
----

## 1. 概要:
    本文档为各三方平台(经销商)提供玖物清洁机器人数据接入方式.

| 版本号 | 修改日期       | 修改人 | 概述                     | 
|-----|------------|-----|------------------------| 
| 1.0 | 2025-11-24 | 关卿  | 初版                     | 
| 2.0 | 2025-12-04 | 关卿  | 根据多多技术人员反馈修改           |
 | 3.0 | 2025-12-15 | 关卿  | 根据多多技术人员反馈修改,添加耗材管理等功能 |
----

## 2. 接入流程
1. 向玖物清洁机器人管理平台申请接入权限;
2. 申请通过后会返回AppSecret和Version;
3. 在请求玖物清洁机器人平台的接口时,将根据规则生成签名与其他参数放入请求头中请求,服务端鉴定通过后放行.

### 申请接入权限
    联系玖物售后人员,获取AppSecret和Version.其中AppSecret要妥善保存.

### 请求头需要的参数

| 参数名称      | 参数类型    | 是否必填 | 描述                   |
|:----------|:--------|:-----|:---------------------|
| appKey    | String  | 是    | 玖物清洁机器人管理平台分配的AppKey |
| timestamp | Long    | 是    | 时间戳(10位)             |
| iv        | String  | 是    | 加密初始化向量,随机字符串(16位)   |
| version   | Integer | 是    | 版本号                  |
| sign      | String  | 是    | 签名                   |

### 签名生成示例(Java)

示例:
```java
public static String encrypt(long timestamp, int version, String appKey,String secret,String iv) throws Exception {
        // 1. 校验参数格式
        if (String.valueOf(timestamp).length() != 10) {
            throw new IllegalArgumentException("时间戳必须为10位long");
        }
        if (version < 1 || version > 99) {
            throw new IllegalArgumentException("版本号必须为1-99的int");
        }
        if (appKey.length() != 16) {
            throw new IllegalArgumentException("appKey必须为16位字符串");
        }

        // 2. 拼接明文（格式：时间戳|版本号|appKey）
        String plaintext = timestamp + "|" + version + "|" + appKey;

        // 3. AES-256-CBC加密
        SecretKeySpec keySpec = new SecretKeySpec(secret.getBytes(StandardCharsets.UTF_8), "AES");
        IvParameterSpec ivSpec = new IvParameterSpec(iv.getBytes(StandardCharsets.UTF_8));
        Cipher cipher = Cipher.getInstance("AES/CBC/PKCS5Padding");
        cipher.init(Cipher.ENCRYPT_MODE, keySpec, ivSpec);
        byte[] encryptedBytes = cipher.doFinal(plaintext.getBytes(StandardCharsets.UTF_8));
        // 4. Base64URL编码
        String sign = Base64.getUrlEncoder().withoutPadding().encodeToString(encryptedBytes);
        return sign;
}
```

### 3.1 Robot接口

#### 3.1.1 查询Robot列表

**请求方式**: HTTP-POST

**接口地址**: http://{ip}:{port}/api/v1/robot/{page}/{limit}

**请求数据类型**: application/json

**响应数据类型**: application/json

**请求分页参数**: 

| 参数名称            | 参数说明   | 类型  | 可为空   |
|-----------------|--------|-----|-------|
| page            | 当前页    | int | false |
| limit        | 每页显示条数 | int | false |


**请求体参数**:
| 参数名称            | 参数说明   | 类型  | 可为空   |
|-----------------|--------|-----|-------|
| robotSn        | 机器人sn     | String | true |
| robotName        | 机器人名称     | String | true |
| robotType        | 机器人型号     | String | true |
| online         | 机器人是否在线     | boolean | true |
| enable         | 机器人是否可用     | boolean | true |
| currentStation | 机器人当前站点     | String | true |
示例:

```json
{
  "robotSn": "string",
  "robotName": "string",
  "robotType": "string",
```

**返回参数**:

|----------------------|--------------|---------------|

| message              | 返回信息         | String        |
| data                 | 列表数据         | Array<Object> |
| data.pageNo          | 分页页号         | int           | 
| data.pageSize        | 分页大小         | int           |
| data.total           | 总记录数         | int           |
| data.list            | 列表数据         | Array<Robot>  |
| Robot.robotSn        | 机器人sn        | String        |
| Robot.robotName        | 机器人名称        | String        |

| Robot.currentStation | 机器人当前站点      | String        |
| Robot.lastOnlineTime | 机器人最后在线时间    | String        |
| Robot.usedField      | 机器人工作区域      | String        |
| Robot.focus          | 机器人是否被选中关注   | boolean       |
