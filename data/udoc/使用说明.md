# Wiki使用说明

## 1. 概述

Wiki文档库支持两种编辑方式：注册后在线编辑方式和GIT同步方式。
文档内部按照小组分布，对外展示使用导航栏按照文档类别划分。

## 2.文档编辑
### 2.1 在线编辑方式

1. 进入网页后注册用户

![登录](./home/login.png =120x50)

2. 联系管理员提升权限，提供可编辑权限
3. 在网页直接增加、修改、删除文档 

![编辑增加按钮](./home/addedit.png =120x50)

### 2.2 GIT同步方式

1. 联系管理员邀请进入知识库coding项目组

![仓库](./home/repo.png =400x100)

2. 通过git方式clone/pull同步当前所有文档
3. 增加、修改文档后提交，等待合并后，wiki平台会自动同步到网页

### 2.3 格式注意点

1. markdown文件中如果出现以下标签可能导致渲染失败，无法同步到页面的情况：
	- `<font></font>`


## 3.文档结构

### 3.1 内部组织

文档内部组织按照小组划分，小组内部在按照文档类别划分，如：
- 1.MCS
- 2.单机
- 3.规控
	- 1）部署文档
  - 2）使用文档
- 4.感知
	- 1）部署文档
  - 2）使用文档
  - 3）开发文档
  

**注意：该文档平台有权限管理，未登录的用户(Guest)只能看到带有"使用说明""部署说明"等标签的文档，如果需要对外展示，请带上这些标签，如果仅对内展示，则不要带上这些标签**
已知的Guest用户能查看的文档标签有：
- 使用说明
- 部署说明
- 公开

可以按照需要增加其他标签

### 3.2 外部展示

文档的外部展示按照文档类别划分，如：
- 项目文档
	- 南通M1项目
  - 成都S9项目
- 部署文档
	- 调度系统部署
  - 单机部署
- 使用文档
	- 机器人使用说明
- 常见问题
	- LOST问题处理

## 4.文档编写规则

1. 文档头部需包含文档基本信息（版本号、部门、密级）和变更记录，示例如下：

| 文件名称 | XXXXXX文档                   |
| -------- | ---------------------------- |
| 部门     | 软件算法部                   |
| 版本     | 1.0                          |
| 密级     | 公开/限制（部门内公开）/保密 |

变更记录：

| 版本号 | 修改日期 | 修改人 | 概述 | 详细说明 |
| ------ | -------- | ------ | ---- | -------- |
|        |          |        |      |          |
|        |          |        |      |          |
|        |          |        |      |          |
|        |          |        |      |          |

2. 文档内不可包含涉密信息，包括但不限于系统用户名、密码、具体的项目名称、客户名称等
3. 文档编写需注意用词规范，描述中不应使用**AGV/小车**，统一使用**机器人/robot**
