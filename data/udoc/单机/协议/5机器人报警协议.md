## 一、概述

该文件主要描述机器人给调度系统发送报警信息的协议，通信通过 UDP 进行，机器人作为UDP单播发送方，调度系统作为UDP服务端接收方。


## 二、数据包解析


机器人内部会持续收集各个设备的报警信息，当收集到的数据有变化后（包括报警信息的增加、减少、更新）都会触发报警数据包的发送，具体的发送格式如下：


```json
{

	"id" : 1739266304823,        // id和name作为数据唯一性标识
	"name" : "Flex500-011",      // 机器人名称
	"action" : "diagcast",       // 固定关键字
	"events" : [
		// 第一个报警信息
		{
			"device": "ucore",   // 发生故障的设备
			"code" : "E0001",    // 错误码
			"msg" : "ap_failed", // 错误详细描述
			"level" : "1"        // "1"表示警告；"2"表示发生错误
		},
		// 第二个报警信息
		{
			……
		}
	]
}
```

以下是各个元素的解释与说明:
- id: UDP数据包的序号，是机器人上报时当前系统时间，单位是毫秒，类型是 `long long int`
- name: 上报的机器人名称
- action: 固定的关键字，用于与其他类型的UDP数据包区分
- events: 报警信息的数组，内部包含一个一个独立的报警信息:
	- device: 发生故障/报警的设备名称
	- code: 设备故障码
	- msg: 设备故障说明信息
	- level: 故障等级，通常来说等级越高表示故障越严重
