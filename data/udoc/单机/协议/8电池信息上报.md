## 信息上报

### 1. 电池信息示例

电池信息上报格式为json类型的字符串, 示例如下

```batteryinfo
{
   "action" : "batteryinfo",	/// 命令字, 固定字段
   "current" : -1.4,            /// 电流(A)
   "id" : 1756661175858,        /// unix格式时间戳
   "name" : "uBot-305",         /// AMR 名称
   "ntc" : 29,                  /// 功率管温度(℃)
   "ntc1" : 26,                 /// 电池温度ntc1(℃)
   "ntc2" : 27,                 /// 电池温度ntc2(℃)
   "vol" : 26.5                 /// 电压(V)
}
```

### 2. 里程计和电池健康程度示例

里程计和电池健康程度上报格式为json类型的字符串, 示例如下

``` basecast
{
   "action" : "basecast",      /// 命令字, 固定字段
   "soh" : 99,                 /// 电池健康程度
   "total_distance" : 199999,  /// 里程计行驶里程(mm)
   "name" : "uBot-305",        /// AMR名称
   "id" : 1756661175858        /// unix格式时间戳
}
```
