# 前端
## 概述
前端操作可以上传下载文件，查看当前服务端的资源及客户端的更新状态
## 上传文件
用户选择文件上传，选择车型和文件位置，可输入版本号

| 参数       | 描述   | 类型     | 备注                         |
| -------- | ---- | ------ | -------------------------- |
| fileName | 文件名  | string |                            |
| file     | 文件流  |        |                            |
| location | 资源位置 | string | 根据现有资源，提供下拉菜单，不需要每次都输入     |
| type     | 车型   | string | 可能多种车型混跑的项目，根据服务端配置，提供下拉菜单 |
| version  | 版本号  | string | 选择配置，若为空，服务端根据文件的md5值作为版本号 |
## 查看状态
用户可查看服务器当前存储的资源列表，根据车型、文件名、资源位置，提供筛选显示，可以选择历史版本进行强制回退，显示版本号和MD5值
用户可查看客户端当前的更新状态，根据车型、文件名、资源位置进行筛选，查看已同步服务端当前版本的客户端列表，显示客户端名称和IP（选择某一条资源）
选择某一个客户端，查看它当前使用的资源版本


# 服务端
## 概要:
____
    提供资源的上传,下载,查询历史版本信息,查询是否需要更新功能

## 1,上传接口
___
    请求地址:http://url:8084/resource/upload/{type}/{location}/{fileName}/{version}/{default}
    请求方式:HTTP-POST
    请求参数描述:
| 名称 | type   | fileName | location | version | default |
|----|--------|----------|----------|---------|---------|
| 类型 | 车型     | 上传文件名    | 文件路径     | 版本号     | 是否是默认版本 |
| 描述 | String | String   | String   | String  | boolean |

    将文件放到请求体中:
```json
{
    "file": "文件流"
}
```
    响应结果:
```json
{
    "code": 200,
    "message": "上传成功",
    "data": null
}
```
```json
{
    "code": 201,
    "message": "上传失败",
    "data": null
}
```
## 2,下载文件接口:下载指定资源
---
    请求地址:http://url:8084/resource/download/{type}/{location}/{fileName}/{version}
    请求方式:HTTP-GET
    请求参数描述: 同上传接口
    响应: 文件流

## 3.查询文件历史版本号
----
    请求地址:http://url:8084/resource/checkVersionList/{type}/{location}/{fileName}
    存疑？希望可以查询所有的资源，参数type、location、fileName可以指定进行筛选
    请求方式:HTTP-GET
    请求参数描述: 同上传接口
    响应结果:
```json
{
  "code": 200,
  "message": "查询成功",
  "data": [
    {
      "version": "1.0",
      "createTime": "2020-08-06 15:03:08",
      "fileName": "test.txt",
      "location": "/usr/***/***",
      "type": "叉车A",
      "md5": "******",
      "fileSize": 0
    },
    {
      "version": "2.0",
      "createTime": "2021-08-06 15:03:08",
      "fileName": "test.txt",
      "location": "/usr/***/***",
      "type": "叉车A",
      "md5": "******",
      "fileSize": 1
    }
  ]
}
```
```json
{
    "code": 201,
    "message": "查询失败",
    "data": null
}
```

## 4.查询本地版本是否最新
----
    请求地址:http://url:8084/resource/checkVersion/{type}/{location}/{fileName}/{version}
    存疑？想要查询服务端所有客户端的下载/更新记录
    请求方式:HTTP-GET
    请求参数描述: 同上传接口
    响应结果:
```json
{
    "code": 200,
    "message": "当前已是最新版本",
    "data": null
}
```
```json
{
    "code": 201,
    "message": "当前不是最新版本,有最新版本:3.0",
    "data": null
}
```
## 5.删除指定资源
    请求地址:http://url:8084/resource/remove/{type}/{location}/{fileName}/{version}
    请求方式:HTTP-GET
    请求参数描述: 同上传接口
    
    响应结果:
```json
{
    "code": 200,
    "message": "删除成功",
    "data": null
}
```
```json
{
    "code": 201,
    "message": "删除失败",
    "data": null
}
```
