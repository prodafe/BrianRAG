# 2. GLM 模型充值与 API 调用
### 2.1 GLM 模型充值流程
- 登录智谱 AI 开放平台：https://open.bigmodel.cn/；
- 进入「个人中心」→「余额充值」；
- 选择充值金额（支持 1 元起充），通过支付宝 / 微信完成支付；
- 充值完成后，可在「余额明细」中查看到账金额。
### 2.2 API-KEY 获取
- 登录平台后，进入「控制台」→「API 密钥管理」；
- 点击「创建 API 密钥」，复制生成的api_key（格式：sk-xxx）；
- 密钥管理：支持多密钥创建 / 禁用，建议按用途分类管理。
### 2.3 API 调用示例（对话 / 代码交互）
```python
import requests
import json

# 配置信息
GLM_API_KEY = "你的GLM API-KEY"
GLM_API_URL = "https://open.bigmodel.cn/api/paas/v4/chat/completions"

# 请求头
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {GLM_API_KEY}"
}

# 调用GLM-4模型
def call_glm_model():
    data = {
        "model": "glm-4",
        "messages": [
            {"role": "user", "content": "用GLM模型优化一段Java多线程代码，提升并发效率"}
        ],
        "temperature": 0.8,
        "max_tokens": 4096
    }
    response = requests.post(GLM_API_URL, headers=headers, json=data)
    result = response.json()
    print("GLM模型响应：\n", result["choices"][0]["message"]["content"])

call_glm_model()
```
### 2.4 对话形式使用
- 登录智谱 AI 平台「对话中心」：https://open.bigmodel.cn/chat；
- 选择模型版本（如 GLM-4、GLM-3-Turbo）；
- 在对话框中输入代码需求 / 问题，实时交互；
- 高级设置：可调整「温度」「最大生成长度」等参数，适配不同场景。

# 3. Minimax 模型充值与多工具接入
## 3.1 Minimax Token 充值流程
- 步骤（基于https://platform.minimaxi.com/subscribe/token-plan）
- 登录 Minimax 平台：https://platform.minimaxi.com/；
- 进入「订阅」→「Token 套餐」页面；
- 选择套餐类型（按量计费 / 包月套餐），确认金额后完成支付；
- 充值完成后，Token 自动到账，可在「个人中心→我的 Token」查看余额。
### 3.2 OpenClaw 接入配置
- 基础配置（基于https://platform.minimaxi.com/docs/token-plan/openclaw）
- 获取 Minimax 凭证：
- 登录平台→「开发者中心」→「API 密钥」→生成api_key和api_secret；
#### OpenClaw 调用示例：
```python
from openclaw import OpenClawClient

# 初始化客户端
client = OpenClawClient(
    minimax_api_key="你的Minimax API-KEY",
    minimax_api_secret="你的Minimax API-SECRET",
    minimax_model="abab6.5-chat"
)

# 对话调用
response = client.chat.completions.create(
    model="abab6.5-chat",
    messages=[
        {"role": "user", "content": "用OpenClaw调用Minimax模型，生成一段Go语言的并发任务调度代码"}
    ]
)
print("OpenClaw调用结果：\n", response.choices[0].message.content)
```

#### 二、配置说明（全部优化好）
1. 聊天模型（主模型）
- abab6.5-chat：最强代码能力，稳定、便宜
- temperature: 0.1：代码最精准、不乱编
- maxTokens: 8192：支持长代码
- contextWindow: 16384：支持读取大文件
2. 自动代码补全（实时续写）
- abab6.5s-chat：速度最快、最适合补全
- temperature: 0：最稳定、不瞎猜
- tabAutocompleteEnabled: true：开启自动补全
3. 体验优化
- 自动补全缓存：开启（更快、省 Token）
- 关闭遥测：保护隐私
- 关闭调试日志：不卡顿、不刷屏
