# 继电器及继电器模块-产品知识介绍

# **一、继电器基本原理**

​        继电器核心结构包括线圈（输入回路）和触点（输出回路）。当线圈两端施加额定电压时，线圈产生电磁力，吸合衔铁，带动触点组动作——常开触点闭合、常闭触点断开；当线圈断电时，弹簧复位，触点恢复原始状态。

核心功能：实现“弱电控强电”或“低压控高压”，同时实现输入与输出之间的电气隔离。



## **二、按原理分类**

| 类型              | 特点与应用                                                   |
| ----------------- | ------------------------------------------------------------ |
| 电磁继电器        | 最传统，利用电磁铁吸合触点，寿命长，负载能力强               |
| 固态继电器（SSR） | 无机械触点，用半导体开关，寿命极长、无噪音、响应快，适用于频繁启停、防爆场合，但有过热问题，需配散热器，注意浪涌电流 |
| 时间继电器        | 带延时功能（通电延时/断电延时），用于时序控制                |
| 热继电器          | 利用双金属片受热弯曲，用于电机过载保护，整定电流范围需覆盖电机额定电流，通常按1.05~1.2倍额定电流设定 |



## **三、继电器模块基本原理**

​        “继电器模块”通常是指将继电器、底座、接线端子、保护电路（如续流二极管、RC吸收回路）以及状态指示灯等集成在一起的标准组件。相比单个继电器，模块化产品能大幅减少布线工作量，提高系统可靠性和维护便捷性，在工业自动化控制柜中应用极为广泛。



### **四、继电器模块核心特点与优势**

#### 1. 即插即用，布线简化

#### 所有接线汇集于模块端子上，无需为每个继电器单独配底座和飞线，柜内布线整洁

#### 2. 维护便捷

继电器本体可插拔，故障时直接拔下更换，无需拆线

#### 3. 状态可视

每个通道均有LED指示灯，线圈状态一目了然

#### 4. 保护电路内置

续流二极管、RC吸收等保护元件已集成，无需外部加装

#### 抗干扰增强

模块化设计通常考虑电磁兼容性（EMC），减少相互干扰

### 关键选型参数

通道数与触点形式

通道数：1路、2路、4路、8路、16路等。根据PLC输出点数及控制对象数量确定。

每路触点形式：常见有1NO（1常开）、1NO+1NC（1常开1常闭）、2NO（2常开）等。需与负载控制要求匹配。

线圈参数

额定电压：DC 24V最常用（PLC输出多为DC 24V），也有AC 220V、AC 24V等。

线圈功耗：通常0.5W~1W（DC），确保PLC输出模块有足够驱动能力（多数PLC单点输出容量≥0.5A，驱动能力充足）

触点容量

额定负载：如10A 250VAC / 10A 30VDC。需满足负载（电机、电磁阀、加热器）的电流和电压要求。

最小负载：若切换微小信号（如<10mA），需选择镀金触点或固态继电器模块，避免接触不良。
