# 标定要求

一块长度在6米以上的场地；

机器人定位分数应尽可能高且稳定，稳定指的是机器人移动时定位分数跳动不大；


# 标定说明

*可以标定的车型：全向车；

*需要和嵌入式的同事确认机器人是否支持"ROS话题临时修改车轮补偿角度"，如果支持则可以使用"一.支持ROS话题临时改变车轮补偿角度"和"二.不支持ROS话题临时改变舵轮补偿角度"，如果不支持则只能使用"二.不支持ROS话题临时改变舵轮补偿角度"进行车轮标定；

*标定任务中，机器人会以右前方/左后方方向移动；

*修改车轮补偿值的文件位置及修改方法：

文件位置及文件名（不同机器人中，配置文件的文件名可能不同，可以向嵌入式同事确认是哪个文件），举例说明：

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758676333412-471d966b-465a-41a5-b5d8-ddcc6e22169d.png)

车轮补偿参数："left dir"/"right dir"分别表示左/右车轮的补偿值；将标定得出的车轮补偿值写入"data value"中（单位是0.1度）

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758676472863-dc86240f-cb18-4422-8a54-2f9caaaccaf0.png)

<font style="color:#DF2A3F;">刷新配置文件方式：</font>

关闭urobot服务

```json
sudo systemctl stop urobot.service
```

在"~/LogicTestV2"目录下执行脚本（端口号和配置文件名称如果不清楚，可以向嵌入式同事确认）

```json
./qz_update_arm_1.1 /dev/端口号 配置文件名称
```

例如：

```json
./qz_update_arm_1.1 /dev/ttyS0 qz_init_steer_zhuazhou_0922.json
```

等待终端出现下图提示后，可以用"ctrl+c"结束

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758678837884-2246fb93-b26c-4afc-91a7-0f0ebb02b580.png)

重启urobot

```json
sudo systemctl restart urobot.service
```

# 一.支持ros话题临时改变舵轮补偿角度

## 标定流程

<font style="color:#DF2A3F;">*在进行标定之前，需要将配置文件中的车轮补偿值设置为0并刷新配置文件(刷新方式见"标定说明")；</font>

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758784841924-e0b1017f-0b16-4a29-82fb-f4b71a284e39.png)



*设置好参数，执行标定任务

```json
"cmd": "helm_angle_calibration",

"circle_collect_data_num": 1500,		// 拟合圆弧时，需要采集的数据量(当"calibrate_target": "circle"时使用此参数)(采集的数据量越多，机器人需要移动的距离就越长，采集100个数据点大约需要6分米，根据场地长度设置本参数)(默认值:2000)
"line_collect_data_num": 1500,			// 拟合直线时，需要采集的数据量(当"calibrate_target": "line"时使用此参数)(采集的数据量越多，机器人需要移动的距离就越长，采集100个数据点大约需要6分米，根据场地长度设置本参数)(默认值:2000)

"vx_cali": 100,   	// 标定时机器人x方向的速度(正数)(单位：毫米/秒)(默认值:100)
"if_hand": 1,			// 标定起始时的移动方向: 1表示正向行驶，2表示反向行驶；标定过程中机器人会前后交替移动(默认值:1)

"x_helm_length": ***,		// 机器⼈x⽅向⻋轮的距离(单位：米)
"y_helm_length": ***,		// 机器⼈y⽅向⻋轮的距离(单位：米)

"circle_precision": 1,	// 拟合圆弧时，要求达到的精度等级，等级越高，标定的越准确(默认值:1)
"line_precision": 1,		// 拟合直线时，要求达到的精度等级，等级越高，标定的越准确(默认值:1)

"max_circle_calibrate_times": 6,		// (支持ROS话题临时改变舵轮补偿角度)在拟合圆弧的标定中，最大标定次数(默认值:10)
"max_line_calibrate_times": 6,			// (支持ROS话题临时改变舵轮补偿角度)在拟合直线的标定中，最大标定次数(默认值:10)
```

参数说明

*x参数说明：x：机器人x方向车轮的距离；y：机器人y方向车轮的距离；z：两个车轮的直线距离(单位：米)

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758788695814-fd61060a-33ff-4780-ba0c-a89e40abd71a.png)



*标定结束后，查看该任务最后的日志，在配置文件修改补偿值并刷新配置文件；

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1759039440472-63a60e27-74dc-4d48-9cb6-a6a4bcc24077.png)

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1759039611280-8c597ce9-a073-4541-89ba-82127bfcf0a8.png)



标定逻辑：机器人在标定过程中，会先通过拟合圆弧标定车轮，在满足精度等级"circle_precision"后，会再通过拟合直线标定舵轮，在满足精度等级"line_precision"后，标定结束；

如果机器人标定次数超过最大标定次数("max_circle_calibrate_times"/"max_line_calibrate_times")，则任务会失败，需要重新标定；







# 二.不支持ros话题临时改变舵轮补偿角度

## 标定步骤

标定分为两个步骤，分别为"通过拟合圆弧标定车轮"和"通过拟合直线标定车轮"。



## 一.通过拟合圆弧标定车轮

### 目的

使机器人的移动路线是直线而不是圆弧；

### 标定具体过程

<font style="color:#DF2A3F;">*在进行标定之前，需要将配置文件中的车轮补偿值设置为0并刷新配置文件(刷新方式见"标定说明")；</font>

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758784841924-e0b1017f-0b16-4a29-82fb-f4b71a284e39.png)



*执行拟合圆弧标定任务，机器人会向右前方和左后方交替移动（移动一个来回算标定两次）；

```json
"cmd": "helm_angle_calibration",

"only_get_theat_pub": true,				// 只通过标定获得舵轮补偿值，不支持ros话题临时修改舵轮补偿角度(默认值：false)
"calibrate_target": "circle",			// 拟合圆弧标定舵轮
"calibrate_num": 6,								// 标定的次数(机器人移动一个来回算2次标定)(次数越多，获得的车轮补偿值越稳定准确)(默认值：1)

"circle_collect_data_num": 2000,		// 拟合圆弧时，需要采集的数据量(当"calibrate_target": "circle"时使用此参数)(采集的数据量越多，机器人需要移动的距离就越长，采集100个数据点大约需要6分米，根据场地长度设置本参数)(默认值:2000)

"vx_cali": 100,   	// 标定时机器人x方向的速度(正数)(单位：毫米/秒)(默认值:100)
"if_hand": 1,			// 标定起始时的移动方向: 1表示正向行驶，2表示反向行驶；标定过程中机器人会前后交替移动(默认值:1)

"x_helm_length": ***,		// 机器⼈x⽅向⻋轮的距离(单位：米)
"y_helm_length": ***,		// 机器⼈y⽅向⻋轮的距离(单位：米)
```

参数说明：x：机器人x方向车轮的距离；y：机器人y方向车轮的距离；z：两个车轮的直线距离(单位：米)

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758788695814-fd61060a-33ff-4780-ba0c-a89e40abd71a.png)



*标定任务结束后，查看机器人本体日志，举例说明：

本次执行了标定次数为2的任务

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758784025190-7950afb7-3f0a-4a76-b1f7-96bfc905871c.png)

任务结束后，查看任务最后的部分，任务成功会返回1，将车轮平均补偿值填入配置文件中并刷新配置文件；

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758784150493-21341708-34c3-44df-aeb8-b5a7663bbbf5.png)

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758784387480-81023fe6-2bda-42a9-bfb0-36d248f1bec0.png)



### 检测标定效果方法

方法一：通过manager前后移动机器人，观察机器人是否以圆弧移动，如果明显以圆弧移动过，则需要重新进行"拟合圆弧标定任务"；

方法二：再次执行"拟合圆弧标定任务"，如果日志中显示的精度等级比标定前高，则说明标定有效果；例如本例的标定中，2次标定的精度等级分别为2和1；![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758784471827-262721b3-015a-44e8-99fb-53fc69bb06bb.png)

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758784505995-850f0681-a3fd-40bb-bcec-fc61344f6ec9.png)

<font style="color:#DF2A3F;">如果需要重新进行"拟合圆弧标定车轮任务"，则需要先将配置文件中的车轮补偿值重置为0并刷新配置文件，再重新标定；</font>![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758784841924-e0b1017f-0b16-4a29-82fb-f4b71a284e39.png)



## 二.通过拟合直线标定车轮

### 目的

使机器人走直线时没有角度偏差；



### 标定具体过程

*执行标定任务，机器人会向右前方和左后方交替移动（移动一个来回算标定两次）；

```json
"cmd": "helm_angle_calibration",

"only_get_theat_pub": true,						// 只通过标定获得舵轮补偿值，不支持ros话题临时修改舵轮补偿角度(默认值：false)
"calibrate_target": "line",						// 标定目标：拟合直线标定舵轮
"calibrate_num": 6,									// 标定的次数(机器人移动一个来回算2次标定)(次数越多，获得的车轮补偿值越稳定准确)(默认值：1)

"line_collect_data_num": 2000,			// 拟合直线时，需要采集的数据量(当"calibrate_target": "line"时使用此参数)(采集的数据量越多，机器人需要移动的距离就越长，采集100个数据点大约需要6分米，根据场地长度设置本参数)(默认值:2000)

"vx_cali": 100,   	// 标定时机器人x方向的速度(正数)(单位：毫米/秒)(默认值:100)
"if_hand": 1,			// 标定起始时的移动方向: 1表示正向行驶，2表示反向行驶；标定过程中机器人会前后交替移动(默认值:1)

"x_helm_length": ***,		// 机器⼈x⽅向⻋轮的距离(单位：米)
"y_helm_length": ***,		// 机器⼈y⽅向⻋轮的距离(单位：米)
```



*标定任务结束后，查看机器人本体日志，举例说明：

执行标定次数为2的任务

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758785271037-535eebaa-7618-4ee4-99b6-9a15629409b0.png)

任务结束后，查看日志中任务最后的部分，任务成功会返回1，将"车轮平均补偿值"加在之前拟合圆弧标定出的补偿值的基础上，填入配置文件中并刷新配置文件；

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758785454368-1faea87e-b428-4b9b-8d1f-926344470386.png)

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758785633418-2f776dd3-92e5-49f6-a3e7-b1e7cb20c5bd.png)



### 检测标定效果方法

方法一：通过manager前后移动机器人，观察机器人走直线时是否有角度偏差，如果有明显的角度偏差（如机器人前进时应该向正前方移动，但实际向左前方移动），则需要重新标定；

方法二：再次执行"拟合直线标定车轮任务"，如果日志中显示的精度等级比标定前高，则说明标定有效果；例如本例的标定中，2次标定的精度等级分别为0和0；

![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758785721681-ce6f8be6-2ba2-4805-9ec3-f78b0e462381.png)![](https://cdn.nlark.com/yuque/0/2025/png/35951869/1758785749766-617e0602-22b1-41a6-a803-cfaf440bde96.png)

<font style="color:#DF2A3F;">如果重新进行"拟合直线标定车轮角度"，则应将标定出的"车轮平均补偿值"加在之前通过"拟合圆弧标定车轮"得出的补偿值的基础上</font>，如之前拟合圆弧得出的左/右车轮补偿值为1/-1，重新进行直线拟合得出的左右轮补偿值为6/6，则新的车轮补偿值应为7/5；

# 参数汇总

```json
"cmd": "helm_angle_calibration",

"only_get_theat_pub": true/false,				// 是否 只通过标定获得舵轮补偿值(在不支持ros话题临时修改补偿值的情况下使用)(默认值：false)
"calibrate_target": "circle"/"line",	// 标定目标："拟合圆弧标定舵轮"/"拟合直线标定舵轮"("only_get_theat_pub"为true时使用此参数)
"calibrate_num": ***,					// 标定的次数，次数越多，获得的车轮补偿值越稳定准确("only_get_theat_pub"为true时使用此参数)(默认值：1)

"circle_collect_data_num": ***,		// 拟合圆弧时，需要采集的数据量(当"calibrate_target": "circle"时使用此参数)(采集的数据量越多，机器人需要移动的距离就越长，采集100个数据点大约需要6分米，根据场地长度设置本参数)(默认值:2000)
"line_collect_data_num": ***,			// 拟合直线时，需要采集的数据量(当"calibrate_target": "line"时使用此参数)(采集的数据量越多，机器人需要移动的距离就越长，采集100个数据点大约需要6分米，根据场地长度设置本参数)(默认值:2000)

"vx_cali": ***,   	// 标定时机器人x方向的速度(正数)(单位：毫米/秒)(默认值:100)
"if_hand": 1/2,		// 标定起始时的移动方向: 1表示正向行驶，2表示反向行驶；标定过程中机器人会前后交替移动(默认值:1)

"x_helm_length": ***,		// 机器⼈x⽅向⻋轮的距离(单位：米)
"y_helm_length": ***,		// 机器⼈y⽅向⻋轮的距离(单位：米)

"max_circle_calibrate_times": 6,		// (支持ros话题临时改变舵轮补偿角度)在拟合圆弧的标定中，最大标定次数(默认值:10)
"max_line_calibrate_times": 6,			// (支持ros话题临时改变舵轮补偿角度)在拟合直线的标定中，最大标定次数(默认值:10)

"circle_precision": 0/1/2/3/4/5,	// 拟合圆弧时，要求达到的精度等级，等级越高，标定的越准确("only_get_theat_pub"为false时使用此参数)(默认值:3)
"line_precision": 0/1/2/3/4/5,		// 拟合直线时，要求达到的精度等级，等级越高，标定的越准确("only_get_theat_pub"为false时使用此参数)(默认值:3)
```
