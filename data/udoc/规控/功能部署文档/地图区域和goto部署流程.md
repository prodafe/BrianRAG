## 一、概述
该文件描述了机器人导航所使用的routes和返回值，并介绍了在导航过程中会影响机器人的动作的一些内容，如地图区域，机器人位姿以及控制参数。

## 二、地图区域和位姿
### 避障设定区
当机器人进去避障设定区后，机器人的避障范围会根据设定区的名称所设定的值而变化。
避障设定区的命名规则为，FSB三个字母开头规定设定的是前侧后方向，字母后跟的值为将该方向上的避障区设定为多大，不同方向通过#隔开。可以设定一个或多个设定区。
示例：
F-100#S100#B0:前方避障范围为-100，两侧避障范围为100，后方避障范围为0
F-100:仅将前方避障范围设置为-100

### 不旋转后退区
不旋转后退区仅在有rms的情况下可以使用，通常用于避免机器人在走出机台过程中旋转导致撞到机台。可用在任何需要机器人后退且不想要机器人旋转的情况（通过设置机器人位姿同样可以实现）。
**注意**：地图上的主路不应该在不旋转后退区中

### 机器人位姿
机器人地图点位上设置对应的posture之后可以设置让机器人使用对应的位姿进行移动。posture规定了不同车型的位姿，由:隔开，这里只介绍了差速车的位姿设置因为没有:。具体设置请查看《地图格式说明》
差速车仅支持前进和后退。前进无需设置，后退将posture设置为180即可。(configs.json中module:planner:goto_global_planner中的"planner_name"为topology_node_planner时)
如果是使用的rmspath，那么后退位姿使用B
![posture.png](/规控/image/posture.png)
**注意**:设置机器人后退行走的时候还需要将configs.json中的is_backward设置为true


### 转盘位姿
转盘姿态信息为字母加角度的组合，支持3种字母(注意目前仅支持大写)，代表三种转盘姿态，后面跟角度，分别为：
R0 ：转盘转动到机器人的0度,相当于运行了turntable_rotate到机器人的0度
M90 ：转盘转动到地图的90度,相当于运行了turntable_rotate到地图的90度
K-50 ：转盘姿态保持到地图的-50度，相当于运行了turntable_keep到地图的-50度

举例如下：
180:::K-90，代表差速车后退（B），舵轮车和叉车未定义， 转盘姿态为姿态保持到地图的-90度（K-90）

转盘信息会在到达此信息的起始点的时候，运行命令，然后机器人再继续走，如p1 p2 p3 三个点，p1到p2未定义角度，p2 到p3 定义了:::R0，那么机器人的状态如下：
如果起始状态机器人的转盘角度不在R0附近，那么机器人在走到p2点后停下来，会运行姿态信息，转盘转到0度，然后再继续运行到p3点；
如果起始状态机器人的转盘角度就是R0附近，机器人就不会停车，直接运行到p3
## 三、routes模板
```
{
 "cmd": "goto",//现场通常为rms_goto
 "target": "goal",
 "goal": "G1"
}
```
## 四、返回值
1：成功到点
0：移动超时；找不到目标点；目标点无法到达
2：规划控制认为到点失败
## 五、控制参数
1. 平滑
平滑开启后能够使机器人在拐角旋转时直接弧线拐弯，而不是原地旋转方向后再动。可以有效避免一些转弯让定位飘导致来回摆头的问题。
![平滑开启1.png](/规控/image/平滑开启1.png)
![平滑开启2.png](/规控/image/平滑开启2.png)

第一张图是整体平滑的开启，需要将参数配置改为图中配置。
第二张图是规划过程中的平滑，现场通常需要将out_plan_mode中的enable_smooth改为true
2. 速度控制
机器人的速度由三个地方控制，底层的json，上层的configs.json和routes速度。
configs.json中的配置位置为module:track下，然后module:track:fuzzy_param下则是高精度对接状态下的参数。高精度对接意为机器人在最后到点的情况下将尽可能使机器人位置和点位一致。track下的is_dock改为true开启高精度对接。
|参数|作用|
|:-:|--|
|angle_diff1_stop|两个相邻点角度大于该值，机器人需要停车旋转|
|angle_diff2_stop|和机器人当前点角度相差该值弧度的点，也是停车点|
|angle_precision|机器人的到点角度精度阈值|
|init_angle_vel|机器人的最小角速度|
|init_vel|机器人的最小线速度|
|max_acc|机器人的最大加速度|
|max_angle_acc|机器人的最大角加速度|
|max_angle_vel|机器人的最大角速度|
|max_vel|机器人的最大线速度|
|min_acc|机器人的最大减速度|
|min_angle_acc|机器人的最大角减速度|
|min_angle_vel|机器人的反向最大角速度|
|min_vel|机器人的反向最大线速度|
|pose_precision|机器人的到点位置精度阈值|
