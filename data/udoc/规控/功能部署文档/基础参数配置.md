## 一、概述
该文件描述了机器人尺寸和激光位置在部署过程中需要配置的位置和相关参数的对应关系，并简单说明了jarvis-g文件读取的逻辑。

## 二、jarvis-g文件路径
jarvis-g读的配置参数是根据params.json中的参数配置的文件。
```
"x1": {
"params_type": "dir",
"params_path": "device/",
},
"x2": {
"params_type": "file",
"params_path": "device/laser_jarvis.json"
},
"x3": {
"params_type": "json",
"params_path": "device/laser_jarvis.json"
}
```
如上所示，"x1""x2""x3"我们称为是params.json的section。params_type是读取对应文件的方法。
params_type 包含三种类型：dir，file和json。其中dir类型会在robot初始化成功之后才触发。
1. dir对应的文件路径为```param_path+section+'_'+type+'.json'```，如上方为例，假设机器人类型时jarvis_jacking，路径就是device/x1_jarvis_jacking.json。
2. file对应的文件路径就是params_path中配置的路径。
3. json类型则是直接读取{}中的内容。
**注意**：dir类型会在robot类启动后才读取，在此之前会以json的格式保存。因此，当robot的类型为dir时，机器人会先从{}中读取机器人类型，使用激光等参数，然后在启动后再次按照dir类型的路径读取机器人尺寸等数据。

## 四、激光配置
**注意**：jarvis-g和configs.json的配置相互独立，如果想要关闭某个激光，同时关闭两个地方的配置。
激光配置可参考[部署文档](https://p10j68f02n.feishu.cn/docx/Qho7dgCVzoffkcxQoRBcwVhUn1g?from=from_copylink)
1. jarvis-g配置位置
	1. 使用对应激光首先需要在params/robot中将has_xxx改为true，不使用就改为false.
		根据params.json中的配置section，读取对应激光的参数文件，其中"laser"为主激光。
  2. 激光的外参pos_th，pos_x，pos_y的单位分别为度，毫米，毫米。
  3. 激光分为水平安装和垂直安装，垂直安装的激光类型需要是laser_ros_gen_ver，水平安装的则是laser_ros_gen_hor，主激光类型为jarvis。

下列为robot中has_xxx的参数与params.json中对应section。
| 激光 | params.json对应section|robot对应参数|
| --- | ---------- |---------- |
| 主激光 | "laser" |无，默认开启|
| 后激光 | "laser_back" |"has_backLaser"|
| 左激光 | "laser_left" |"has_sideLaser"|
| 右激光 | "laser_right" |"has_sideLaser"|
| 顶部激光 | "laser_top" |"has_topLaser"|
| 底部激光 | "laser_down_slopg" |"has_topLaser"|  
| 其他激光 | "laser1"~“laser9” |无，正确就会开启|
| 深度相机 | "dp_cam” |"has_dpCam"|
| 声纳 | "sonar” |"has_sonar"|
**注意**：深度相机可视为水平相机配置到laser1-9中。

2. configs.json配置位置
如果想要关闭bz中的激光配置，需要将bz激光话题配置中的topic_name改为一个不存在的话题，通常在话题后面加个1即可。
configs.json中需要在module: robot: sensor: laser2d中配置使用的各个激光的角度和位置。
需要配置angle_offset_z为激光角度，单位是度，"pose_offset_x"和"pose_offset_y"是机器人下的激光坐标，单位是米
如图所示，为配置的前后激光参数。
![bz激光配置_前后.png](/规控/image/bz激光配置_前后.png)
需要注意的是左右激光配置需要额外配置两个参数，如图所示
![bz激光配置_左右.png](/规控/image/bz激光配置_左右.png)
其中"detecting_orientation"是激光的朝向，即激光朝着车的哪个方向，有"up"，"down"，"front"，"back"四个方向。
"installation_status"是规定激光是左侧激光还是右侧激光。
"is_zero_to_m_pi"当使用的激光范围为0-180这样的时，需要添加这个参数并设为true

配置中的name是由plugin中的话题配置决定的。如下图所示
![bz激光话题设置.png](/规控/image/bz激光话题设置.png)
例如前激光话题最后使用的topic_name为/front_scan_filtered，在这里规定了这个话题对应的激光名为30c_front，然后就会在sensor中找到对应的激光名读取参数。
topic_name推荐设置与jarvis-g配置文件中的topic一样的内容。

3. urdf
参与定位的激光需要在urdf中配置对应激光的位置参数。通常仅需要配置主激光参数。步骤为
```
roscd 工程名/urdf 
打开urdf文件
找到front_laser_link_joint对应内容。如果要配置其他激光，找到对应激光的link_joint即可
修改rpy的第三个值为激光角度，单位是弧度，xyz的前两个值为激光在机器人下的坐标，单位是米。
如下
<joint name="front_laser_link_joint" type="fixed">
    <parent link="base_link" />
    <child link="front_laser_link" />
    <origin rpy="0 0 0" xyz="0.406 0 0" />
 </joint>
```

## 五、声纳配置
1. jarvis-g配置
使用声纳需要将params.json中的robot中的has_sonar改为true，关闭则改为false。
根据params.json中配置的文件配置声纳。如下所示
```
"count" : 2,
"log" : true,
"p1" : "-485,-170,180",
"p2" : "-485,170,180"
```
count为声纳个数，p1为第一个声纳，三个值分别为x,y和角度，单位是毫米，毫米，角度。其中角度通常使用±90，180和0这样的整数值。依此类推。
具体哪一个声纳为第一个是根据声纳盒规定的，推荐把数值配好后根据manager中的反馈来修改具体是p几。
2. configs.json配置
bz默认使用声纳，如果要关闭，需要在话题配置中修改对应话题。
在module: robot: sensor: sonar中配置，name从"0"开始，每次+1。顺序需要与jarvis-g中的一致。
