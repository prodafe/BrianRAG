## 一、概述
该文件描述了潜伏式机器人关于料架尺寸，腿过滤的尺寸配置位置和一些注意事项。尺寸料架类型，腿过滤的料架类型需要对应且需要通过特定routes进行切换。

## 二、部署简介
配置文件路径为/usr/local/urobot/params/device/robot_jarvis_jacking.json  
需要在在robot_jarvis_jacking.json中配置现场所需要的料架类型的满车尺寸，腿过滤参数。  
**注意**：改变任务对应的料架类型需要在routes中执行cmd为set_shelves_type的routes

## 三、机器人料车尺寸参数
料车尺寸配置在robot_jarvis_jacking.json的"loaded_robot_size"中。
```
"loaded_robot_size" : {
    "default" : {
        "size_length" : 1080,       //料架总长度
        "size_length_front" : 580,  //料架前长
        "size_length_rear" : 500,   //料架后长
        "size_radius" : 742,        //料架旋转半径
        "size_width" : 1100         //料架宽度
    },
    "shelves-BH" : {
        "size_length" : 1080,
        "size_length_front" : 580,
        "size_length_rear" : 500,
        "size_radius" : 742,
        "size_width" : 1100
    }
}
```
如上所示，设置了两个料车类型的尺寸。"default"为默认类型，当没有设置对应料架类型的情况下，就会使用default中的尺寸。  
"shelver-BH"中的料架尺寸需要在routes中使用set_shelves_type的routes去设置成对应的料架类型才会读取该部分尺寸。料架类型可以不断添加。  
**注意**：
尺寸的测量方式为：机器人进入料车，转盘0°转到和料车0°重合后，顶升顶起料架，然后转盘旋转到机器人的0°再测量前后左右。即长边不一定就是长度，而有可能是宽度。


## 四、腿过滤部署
### 功能开启
腿过滤的使用首先要确定/usr/local/urobot/jarvis/share/工程名/param/激光_noise_filter.yaml文件中的working_mode为1。激光是指前后激光，前激光为front_noise_filter.yaml,后激光是back_noise_filter.yaml。深度相机的腿过滤需要特殊部署，根据实际情况考虑。

### 参数配置
腿过滤相关配置在robot_jarvis_jacking.json的"leg_filter"中。
```
"leg_filter" : {
    "use_back_laser" : false,   //是否启用后激光腿过滤
    "use_dp_cam" : false,       //是否启用深度相机腿过滤
    "front_laser_pose" : {      //前激光位置
        "t" : 0,
        "x" : 411,
        "y" : 0
    },
    "back_laser_pose" : {       //后激光位置
        "t" : 180,
        "x" : -397.4,
        "y" : 140
    },
    "dp_cam_pose" : {           //深度相机位置
        "t" : 0,
        "x" : 448.3,
        "y" : 0
    },
    "shelves_type" : {          //对应料车类型的腿，这里面的料车类型需要与loaded_robot_size中的类型对应
        "default" : {
            "filter_radius" : 200,      //腿过滤的过滤半径，这个值通常为料腿长宽值的1.06倍
            "if_start_front" : true,    //是否启用前激光腿过滤
            "if_start_back" : true,     //是否启用后激光腿过滤
            "if_start_dpcam" : false,   //是否启用深度相机腿过滤
            "leg_back" : -460,          //车后料腿的位置
            "leg_front" : 460,          //车前料腿的位置
            "leg_left" : 510,           //车左料腿的位置
            "leg_right" : -510,         //车右料腿的位置，这四个参数开始测量的位置均为料腿中心
            "leg_x_width" : 120,        //料腿长度
            "leg_y_width" : 120,        //料腿宽度，长宽数值最好保持一致，使用长宽最大的那个值
            "dp_filter_radius" : 128,   //深度相机腿过滤的过滤半径，这个值通常为料腿长宽值的1.06倍
            "dp_leg_x_width" : 120,     //深度相机下料腿长度
            "dp_leg_y_width" : 120      //深度相机下料腿宽度，长宽数值最好保持一致，使用长宽最大的那个值
        },
        "shelves-BH" : {
            "filter_radius" : 115,
            "if_start_front" : true,
            "if_start_back" : true,
            "if_start_dpcam" : false,
            "leg_back" : -460,
            "leg_front" : 460,
            "leg_left" : 501,
            "leg_right" : -501,
            "leg_x_width" : 160,
            "leg_y_width" : 160,
            "dp_filter_radius" : 128,
            "dp_leg_x_width" : 120,
            "dp_leg_y_width" : 120
        }
    }
}
```

**注意**：  
1. 腿过滤的生效需要"use_xxx"为true，"xxx_pose"中位置配置正确，"if_start_xxx"为true，三个同时满足才会生效。xxx为对应激光。
2. 深度相机腿过滤仅在料车足够大导致深度相机会看到料腿才会使用。当启用深度相机腿过滤时，深度相机的腿的长宽通常为正常值的3-4倍，可以根据实际情况自行加减。

**可能出现的问题**：
1. 腿过滤不生效。  
   这种情况需要执行指令rostopic echo /front_filter_ctrl (需根据不同激光使用不同话题，深度相机是/dp_filter_ctrl)，执行命令后起顶升，顶升完成后查看有没有类似下图内容:
   ![腿过滤话题.png](/规控/image/腿过滤话题.png)
   如果有类似内容，请检查working_mode是否为1以及腿过滤参数和位置是否正确，或者检查料车类型是否设置；
   如果没有类似内容，请检查注意事项1中的三个参数是否配置正确。
2. 腿过滤不完全，存在噪点。  
   适当增大料腿长宽和过滤半径，如果加大了一定的值之后仍然存在噪点，需要进行录包给相关开发检查。录包指令如下：
   ```
   前激光
   rosbag record /jrotate_res /front_filter_ctrl /front_scan_filtered
   后激光
   rosbag record /jrotate_res /back_filter_ctrl /back_scan_filtered
   深度相机需根据实际情况录包，推荐直接询问部署人员。
   ```

## 五、顶升后尺寸变化
顶升后尺寸变化条件：  
1. robot_jarvis_jacking.json中"enable_resize_jarvis_robot"参数配置为true
2. 使用的default类型或者通过set_shelves_type的routes设置为正确的料架类型

## 六、设置料架类型
```
routes.json:{
    "a": {
      "cmd": "set_shelves_type",
      "type": "shelves-NGK"
   },
}
```
