## 一、概述
该文件介绍了顶升相关的routes的模板。不仅用于托盘顶升，轨道辅助机构的顶升同样适用。

## 二、routes模板
```
//下面是正常顶升的功能
a:{
	"cmd":"lifter",
  "time":0,			//等待时间
  "signal":-1,	//决定升降，0降1升
  "value":-1,		//顶升移动到的位置，单位mm
  "check_qr_angle":false,//是否检查二维码角度
  "QrAngle":0,					//二维码角度
  "check":true					//是否等待顶升完成
}

//下面是对顶升状态检查的routes
a:{
	"cmd":"lifter_check",
  "time":0,
  "state":-1 //
}

```
