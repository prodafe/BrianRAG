## 一、概述
该文件主要解释了机器人安全相关参数的含义。差速安全通常由jarvis-g和bz_robot两个软件同时控制，需要确认机器人尺寸和激光位置的配置在jarvis-g和bz_robot的配置中都配好，可以参考[基础参数配置](/规控/功能部署文档/基础参数配置)

## 二、jarvis-g参数
参数的优先度参考，从高到低为：避障设定区->程序设定->routes中的参数->task.json中对应mode的参数->task.json中avoid的参数。
jarvis-g参数：
| 参数名 |  数据类型      | 默认值      | 概述  |
| :---: | :----------: | :--------: | --------- | 
| "clearance_front_max" | double |   |机器人前方最大避障值 | 
| "clearance_front_min" |double  |   |机器人前方最小避障值  | 
| "clearance_back_max" |double  |   |机器人后方最大避障值  | 
| "clearance_back_min" |double  |   |机器人后方最小避障值  | 
| "clearance_side_max" | double |   |机器人两侧最大避障值  | 
| "clearance_side_min" |double  |   |机器人两侧最小避障值  |
| "clearance_fast_vel" | double |   |  |
| "enable_sonar" | bool |   |是否使用声纳  |
| "enable_sonar_front" |bool  |   |是否忽略前声纳  |
| "enable_sonar_back" |bool  |   |是否忽略后声纳  |
| "enable_sonar_left" | bool |   | 是否忽略左声纳 |
| "enable_sonar_right" | bool |   | 是否忽略右声纳 |
| "ignore_from_when_backward" |double  |   |后退时忽略前方多少的障碍物，正常为正值  |
| "ignore_from_when_forward" |double  |   |前进时忽略后方多少距离的障碍物，正常为负值  |
| "use_forbidden" | bool | true  |是否使用禁区  |
| "use_avoid_area" |bool  |false   |是否使用避障设定区  |
| "real_trans_decel" |double  |800   |机器人实际减速度，仅用于jarvis-g安全计算，通常无需设置  |
| "use_bz_safety" |bool  |false   |是否使用bz_robot的安全，通常需要为true  |
| "security_log" |bool  |false   |是否打印日志，用于记录一些特殊日志  |

## 三、bz_robot参数
bz_robot的安全参数配置在/usr/local/urobot/params/bz_robot_params/configs.json中。
| 参数名 |  数据类型      | 默认值      | 概述  |
| :---: | :----------: |:--------:| --------- |  
| "front_margin" |float  | 0.5  |机器人中心到机器人前边缘距离 | 
| "back_margin" |float  | 0.5  |机器人中心到机器人后边缘距离 | 
| "left_margin" |float  |  0.3 |机器人中心到机器人左边缘距离 | 
| "right_margin" |float  | 0.3  |机器人中心到机器人右边缘距离 | 
| "estop" |bool  |false   |需要刹车时是否需要急停 | 
| "additional_rotate_radius" |float  |0.05   |机器人旋转时的额外半径 |
| "brake_angle" |float  |5   |单位为角度,机器人旋转到距离障碍物该角度会进入刹车状态 |
| "ignore_back_half" |bool  |true   |前进时忽略后方，后退时忽略前方 |
| "debug_saved_path" |string  |""   |watch，slowdown,brake时图片的保存路径，当不配置或配置为“”时不开启。仅在debug时使用 | 
| "image_saved_path" |string  |"/usr/local/urobot/logs/obs_images"   |避障图片的保存路径，默认开启。 |
| "scale_factor" |float  |3.0   |避障图片的缩放比例 |
| "debug_scale_factor" |float  |3.0   |debug图片的缩放比例 |
| "pub_obs_map" |bool  |false   |是否发布传感器检测到的障碍物地图，一般true只在rviz可视化中使用 |
| "x_brake_base_distance" |float  |   |x方向初始避障区距离 | 
| "x_slowdown_distance" |float  |   |x方向的减速区距离 | 
| "x_watch_distance" |float  |   |x方向的观察区距离 | 
| "x_axis_cache" |float  |   |x方向障碍物缓存值,用于解除避障状态。当避障距离小于x/y_axis_cache的斜边时会认为不在避障 | 
| "x_slowdown_linear_vel" |float  |   |x方向的减速区的线速度最大值 | 
| "x_watch_linear_vel" |float  |   |x方向的观察区的线速度最大值 | 
| "y_brake_base_distance" |float  |   |y方向初始避障区距离 | 
| "y_slowdown_distance" |float  |   |y方向的减速区距离 | 
| "y_watch_distance" |float  |   |y方向的观察区距离 | 
| "y_axis_cache" |float  |   |y方向障碍物缓存值,用于解除避障状态。当避障距离小于x/y_axis_cache的斜边时会认为不在避障 | 
| "y_slowdown_linear_vel" |float  |   |y方向的减速区的线速度最大值 | 
| "y_watch_linear_vel" |float  |   |y方向的观察区的线速度最大值 |
| "slowdown_angle" |float  |15   |机器人旋转到距离障碍物该角度会进入减速状态 |
| "slowdown_angle_vel" |float  |0.3   | |
| "turntable_brake_angle" |float  |10   |转盘旋转到距离障碍物该角度会进入刹车状态 |
| "turntable_slowdown_angle" |float  |20   |转盘旋转到距离障碍物该角度会进入减速状态 |
| "move_range_offset" |float  |0.1   |机器人移动距离的偏移量，用于增加直行避障范围 |
| "rotate_range_offset" |float  |0.1   |机器人旋转角度的偏移量，用于扩大旋转避障范围 |
|"back_sonar_idx"|std::vector<std::string>|{""}|设置后声纳是哪几个idx，通常用于转盘旋转时临时关闭声纳功能|
