## 三、移动
|     mode名      | 功能概述                                                                        | 部署文档 |
| :-------------: | ------------------------------------------------------------------------------- | -------- |
|  goto/rms_goto  | 最常用的前往目标点的方法                                                        |          |
|  idle					  | 使机器人处于idle状态用于接取任务                                                        |          |
|  wait					  | 等待一定时间                                                        |          |
|     charge      | 充电用mode，通常通过manger点充电或自动充电触发                                  |          |
|     go_tag      | 先执行goto到点后执行tag，完成后再执行opc。与分别执行的区别是能节省一定的时间    |          |
|    goal_tag     | 同gotag，区别为goaltag前往的点本身是个库位，车会在库位前方一定距离停下后开始tag |          |
| drive/safedrive | 手动开相关mode，通常不会在routes.json中使用                                     |          |
|      move       | 直线行驶，通常用于对接结束后退                                                  |          |
|      head       | 原地旋转                                                                        |          |
|      curve      | 圆弧旋转                                                                        |          |

## 六、通信
|     mode名     | 功能概述                                                                       | 部署文档 |
| :------------: | ------------------------------------------------------------------------------ | -------- |
|     inform     | 与rms进行通信方法之一，有infrom2，inform3等多种变体，需根据实际情况使用        |          |
|     socket     | 与其他网络设备通信方法之一，使用内容为全16进制                                 |          |
|    socket2     | 与inform相似，所发送的内容不同                                                 |          |
|    opc_work    | 潜伏式机器人对接时，如果机台需要opc通讯时使用，有opc_leave/opc_work/opc_inform |          |
|     proxy      | 作为中间站传递机台,rms等服务端与机械臂或车上其他机构的通讯的信息               |          |
| rms_path_point | 用于机器人执行后退一类无rms通信的动作时对路径上的点进行锁点，防止撞车          |          |
|     input      | 获取下位机的io信号，可用于顶升校验等功能                                       |          |
|     output     | 向下位机传输io信号，可用于顶升等功能                                           |          |
